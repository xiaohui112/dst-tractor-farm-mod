# 田边蓄水桶

田边蓄水桶是第七种配套设备，建在田边作为固定补水点。拖拉机挂上洒水机后，可以就近取用储存的雨水。

## 制作与参数

| 项目 | 当前实现 |
|---|---|
| 配方 | 木板 ×2、绳子 ×2、石砖 ×2 |
| 制作栏 / 科技 | 园艺 / 炼金引擎 |
| 初始水量 / 容量 | 0 / 2,000 剂 |
| 蓄水速度 | 普通下雨时每秒 10 剂，累计下雨 3 分 20 秒可从空桶蓄满 |
| 洒水机取水速度 | 每秒 80 剂，有足量存水时 5 秒补满 400 剂水箱 |
| 存放 | 独立建筑，余水随存档保存，可留到冬天或夏天 |

## 使用

1. 在田边放置蓄水桶，驾驶时也可建造。桶与洒水机接近等高。鼠标悬停可看到名称、当前水量和容量，例如「水量 800/2000」。下雨自动积水，停雨后保留水量。
2. 驾驶挂有洒水机的拖拉机靠近并停车，右键「从蓄水桶取水」。车辆会停工，车尾朝向蓄水桶并接上软管。
3. 桶空或水箱满时停止。移动、转向、下车、换挂件或拆除蓄水桶会中断，已补入的水保留。补好水后按 F 继续作业。

取水无需燃料，也不消耗底盘或洒水机耐久。洒水机无法往桶里存水。一桶满水可以给空箱补满 5 次，按默认全干地每格 4 剂估算，合计可浇满约 500 格。[洒水机与三种水源](04-洒水机.md#操作与补水)

## 实现与验证

- 桶是可放置、可锤拆的独立 `aom_rain_barrel` 实体。主机根据世界降雨状态累计水量，在停雨、取水或存档时结算，存水和不足一剂的累计量一同保存。客户端用同步水量显示悬停信息和取水动作。锤拆使用原版建筑掉落流程，存水随桶移除。[蓄水桶 prefab](../../mod/Tractor/scripts/prefabs/aom_rain_barrel.lua)
- 取水复用车辆补水流程。主机验证骑手、实际挂件、距离和余量，按实际转移量扣桶并加入水箱。两辆车可同时取水，合计取水量受桶内存水限制。[取水入口](../../mod/Tractor/scripts/aom_irrigator.lua) · [补水流程](../../mod/Tractor/scripts/aom_pond_refill.lua)
- 离线回归覆盖配方、放置、雨水累计和上限、存档、右键取水、取消与并发扣水。实际建造画面、检查提示和多人同步待进游戏确认。[专项测试](../../tools/tests/test_rain_barrel.py) · [验证说明](../03-版本测试报告与Bug修复.md)

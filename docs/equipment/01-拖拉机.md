# 拖拉机：设计、操作与实现

基线：0.5.1。拖拉机承担驾驶、独立挂载、九格货仓、资源结算和生命周期；农业工序由挂件分发。跨设备作业规则见[核心方案](../01-Mod核心逻辑玩法设计与技术方案.md)。

## 参数与制作

| 项目 | 当前实现 |
|---|---|
| prefab | `aom_tractor_chassis` |
| 配方 | 齿轮4、电子元件3、木板6、燧石8；园艺栏，炼金引擎首次解锁 |
| 生命 / 作业耐久 | 600 / 1000，分别维护 |
| 初始 / 最大油量 | 400 / 800 |
| 货仓 / 挂件 | 原版Container九格 / 独立挂点一个 |
| 空驶速度 | 6世界单位/秒；作业速度按挂件比例，见核心方案 |
| 模型 | 基础倍率2.5，配置相对75%、100%、125%、150%；驾驶人物有逆向比例补偿 |

## 具体操作

1. 选择配方并确认绿色放置位置，世界中生成整车。
2. 右键有油且未损毁的车上车，沿用原版移动控制；无需鞍具、驯化，不接受牛鞍。
3. 驾驶到地面配件附近右键“挂载”。换件先右键已挂配件“卸载”，人留在车上。
4. 左键自己/车身，或点击货仓表盘开关仓库；右键自己/车身下车。下车关仓并停工。
5. 按F开关持续作业。挂卸、换播种策略、上下车后需重新开启。
6. 下车手持燃料右键车身加油，手持齿轮右键修理；满油或生命/耐久全满时不消耗对应材料。

配件不能拿进背包；本车仅能挂一件，不能抢走其他车的配件。挂载服务端距离为5加双方碰撞半径，并核验当前骑手和正机械耐久。卸载在半径3～18的候选点寻找可通行且没有阻挡的位置；无安全位置保留挂件。损毁/移除的强制释放可退回当前附近位置，优先保证实体不丢失。

## 补给与修理

燃料必须有有效fuel组件，fueltype为空或BURNABLE且fuelvalue为正有限数；以该物品实际fuelvalue增加油量，投入一份并封顶800，超过剩余容量的部分不返还。行驶、待机和池塘取水不直接扣油；农业结算才扣。

每份齿轮同时增加100生命及100作业耐久，分别封顶。底盘耐久归零禁止农业作业，但不等同于生命归零。六种配件在地面用燧石修，每份+10；底盘保留四类旧挂件的手持燧石兼容修理入口，现行统一操作是卸载后修地面设备。

仓库允许种子、肥料和普通货物，不保留“第一格挂件槽”。装料入口按容量移动可接纳数量；接收失败尽量退回原库存槽位，无法退回时落在来源位置，不隐藏吞物。

## 承伤、残骸与拆除

车体带Health、Combat、Rideable，Combat禁止坐骑攻击。驾驶员仍由原版生物索敌，普通近战经原版骑乘链路转给车体；远程、电击、黑暗等遵循原版例外。停放空车不作为普通战斗目标。

生命归零立即下车和停工，挂件与货物落地，保留灰暗且可保存的残骸，不自动返还材料或消失。齿轮原地修复；有油且生命恢复后可再驾驶，货物与挂件需要重新装回。油量和计划保留。

锤拆需要4点HAMMER工作量，掉落齿轮2、电子元件1、木板3、燧石4并删除车体，不生成打包车。正常锤拆若挂件没有安全落点，会保留车辆等待重新处理。

## 实现与存档

[prefab](../../mod/Tractor/scripts/prefabs/aom_tractor_chassis.lua)构造网络变量，再在主模拟端添加健康、骑乘、移动、底盘FiniteUses、Workable、Container和AttachmentStore；客户端不添加农业组件。

原版Rideable/Rider和SGwilson处理上下车；[SGaom_tractor](../../mod/Tractor/scripts/stategraphs/SGaom_tractor.lua)提供坐骑实体状态。驾驶外观通过[aom_driver_visual](../../mod/Tractor/scripts/aom_driver_visual.lua)覆盖驾驶bank与驾驶室build，保留角色原build、皮肤和衣帽；独立挂件按同步骑手位置跟随，收割机在前，其余在后。

OnSave保存油量、挂件独立记录、策略、音乐开关与计划，原版组件保存生命、底盘耐久及货仓。挂件随车保存时不再独立持久化，恢复失败则落地。读档保持停工；旧仓库内挂件迁移到独立挂点，旧打包车受阻保留原归属并自动重试。

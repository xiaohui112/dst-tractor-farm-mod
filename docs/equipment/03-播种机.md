# 播种机：操作与当前实现

算法设计、证明边界和性能数据见[巨大化最优详细报告](../reports/巨大化最优设计与验证报告.md)，版本演进见[开发日志](../02-开发进度.md)。

## 参数与成本

| 项目 | 当前实现 |
|---|---|
| prefab/类型 | aom_seeder / seeder |
| 配方 | 木板2、绳子2、普通种子5；园艺栏，炼金引擎 |
| 机械耐久/维修 | 200，燧石每份修50 |
| 物料 | 15格货仓的种子，巨大化只用可识别的具体作物种子 |
| 选地与效果 | 处理驾驶员当前所在格，种子效果落在实际播下的坑位 |
| 成本 | 每颗消耗1份种子；本轮本格第一颗成功时扣1燃料和1底盘耐久，播完扣1挂件耐久 |

顺序策略在本格空坑种完时扣挂件耐久；巨大化在本格最后一个计划坑种下时结算，必要留空不影响。中途缺料/缺油/停工不提前扣挂件耐久，续种或读档后完成才扣。待播土坑保存本轮的燃料和底盘结算状态。最后1点耐久可完成整格；失败无副作用、空跑、重复经过完成地皮不扣。收获重整后的新一轮重新结算。

## 操作与三种策略

先开垦完整九宫格空田。挂载、装种子后，空手左键挂件表盘按“顺序→巨大化·模版→巨大化·最优”切换，切换停工并清旧预览；按F开始。原版移动控制驾驶，经过目标地皮播种。规划完成同步绿色待播坑，提示完成后等待2秒自动播种，无需手工确认。右键表盘卸载，持燧石点击优先维修。图标角上有循环箭头，下方展示当前模式，悬停提示下次切换到的模式。首次挂载时提示操作，4秒后消失。

| 策略 | 选择与保证 |
|---|---|
| 顺序 | 取货仓第一个有效种子，逐颗种本格空坑；不承诺巨大化位置/配比 |
| 巨大化·模版 | 审核目录完整图案、允许的角色替换和方向整块选配；剩余整块空地可用程序模板派生的9株补块，借全田同族；不改原模板及其内部空坑；无固定连通地皮总数上限，不承诺数量最优 |
| 巨大化·最优 | 起点四边连通完整空九坑，最多64地皮；证明最大合法数量后，优先统一同配比整体图案，再整理行列和留空；同族硬条件保留 |

两种巨大化共用应季、库存、实际坑距/密度、逐株同族与逐地皮三类养分净零。不读取当前肥力，也不因贫瘠提示缺肥。最优策略的单格4＋4允许空坑在任何合法位置，中心留空仅是数量确定后的整齐偏好；5＋4能否补满仍由逐格养分等硬条件决定。模版策略按目录保留原图及固定空坑。

模版先保留完整模板方案，再只对未被任何模板占用的地皮尝试补块；截图模板不拆分，必要空坑不填。补块从程序18株模板派生，采用3＋3＋3或3＋6及原有允许的角色映射、旋转/镜像。锁定截图模板时不引入其他模板；锁定程序18株模板时可使用它自己的派生补块。同族按全田实际范围关系校验，养分仍逐地皮互补。邻接空块每组最多6块共同选配，总补块搜索额度12000步，支持分帧与取消；无法合法增加时保留原方案，不承诺任意田形都填满。[本次验证证据](../evidence/template-supplements-2026-11-17/report.md)。

## 现场、进度与存档

新坑偏移−1.3125/0/+1.3125，旧坑依实际坐标识别。范围与坑距关系交给原版FindEntities，不额外加epsilon。完整九坑、空田与连通性由扫描复核，不完整地皮不能当桥梁。

巨大化预规划、按 F 扫描和预览结束后的落种都以驾驶员当前所在格为准。预览期间驶离时，驾驶员重新进入计划范围才会落种。

开种后锁定全田计划；缺种、缺坑、作物冲突、季节变化保留进度停工，处理后按F继续，不改种、不拔除。模版每次播种复核当前完整模块及余种；补块还重扫覆盖同族半径的邻地，以实际坑位/作物验证同族，不随整片田面积扩大扫描范围。最优复核当前计划现场；原版回调异常按实际改动结算。完成计划保留索引，收获并恢复九坑后开始新轮。

v4保存实际坐标、完成索引、季节、策略与养分互补标记；模版保存模块编号、原点、方向和角色。旧计划兼容续种，不能把旧存档坐标改成新坑距。读档不自动作业；运行期田地索引不是持久保证，重新按现场恢复。

## 调度、计时与显示

服务端协程分帧推进。房主/服务器在 Mod 设置的“巨大化规划每帧额度”选择2/4/8/12/16/24/32ms，默认16ms；保存并重新载入世界后生效，无需改代码或重新打包。它适用于最优和模版的前台规划；后台预计算固定1ms。可按流畅度调整，卡顿时降低额度；24/32ms可能明显卡顿。额度为世界共享的软CPU预算，单次恢复可能超额，每次最多1024次恢复。数量证明无超时少播降级，可按F停止；排列有有限工作量预算。最优允许骑乘空闲时稳定两次采样后预计算，模版不走该后台入口。

最多8项完整方案缓存、4项挂起任务，按库存、实际坑位、季节、规则和目录版本失效。缓存不跨存档持久化。预计算不扣料、不种植；提交前核对输入。

保留头顶进度、完成/取消反馈与内存计时。前台规划完成、取消或失败时，以 `[Tractor][plan …]` 开头打印一次控制台结果；驾驶者按 `~` 打开本地控制台回看，远端驾驶者通过定向RPC收到同一条结果，服务端标准输出也会留存。包含实际经过时间、任务计算时间、每帧额度；完成时还包含数量与排列阶段计算时间。后台预计算与进行中的进度不打印，不创建独立规划日志文件。数量与排列CPU累计排除跨帧等待，不能直接换算首种墙钟等待或FPS。

最优预览沿用受限协议；模版D6仅同步附近完整模块，半径沿两轴±20世界单位，最多64模块、512株待播点、24000字符。该窗口不截断服务器全田计划。下车、切策略和完成清预览。

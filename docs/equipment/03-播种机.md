# 播种机：设计、操作与实现

基线：0.5.6。将种子放入空农田坑位；普通策略处理本格，配比策略按固定坐标工作，不修改作物生长或巨大化判定。

## 参数与补料

| 项目 | 实现 |
|---|---|
| prefab / 类型 | `aom_seeder` / `seeder` |
| 配方 | 木板6、绳子4、普通种子20、齿轮1；园艺栏，炼金引擎 |
| 机械耐久 / 修理 | 400；地面燧石每份+10 |
| 物料 | 九格货仓中具有farmplantable组件的种子；普通种子可用于普通策略 |
| 结算 | 每颗成功种植消耗种子1、油1、底盘耐久1、机械耐久1 |
| 作业速度 / 批次 | 约4.7143世界单位/秒；每个驶入地块最多尝试10颗 |

将种子放入任意货仓格，或挂载后下车手持种子右键车身装料。缺种立即停工，失败且种子实体仍有效时退回货仓；无法入仓则按库存适配保留物品，不继续无效消耗。

## 普通播种操作

挂载后点击最右侧配件表盘，打开播种设置，再点击循环箭头；不再常驻下方种子状态条。顺序为顺序→随机→配比→顺序。切换策略停止作业并清除原配比计划，再按F开启。再次点击表盘关闭设置。满耐久400可种完货仓9组40颗、共360颗种子后剩40耐久；仍需要足够的燃料、底盘耐久和可播种土坑。旧存档保留原剩余耐久数，不自动补满。

- 顺序：按货仓槽位列出的有效种子堆取一颗，成功后继续取下一颗。
- 随机：均匀抽取一个有效种子堆，再拆一颗；不是按总种子数量加权。因此一种作物放多个槽位会影响抽取概率。
- 两者仅搜索当前地块有效空farm_soil，不补种相邻格；停车不会不断播种。

## 配比操作

1. 准备本季整套作物种子，切到“配比”，将车驶到计划起点。
2. 点击配件表盘打开设置，点击“预览”，或首次按F仅生成预览。绿色标记不是真土坑，不改地、不扣资源。
3. 可每次旋转90°，悬停看作物数量、范围、方向和下一格。点击“确认”时重新检查模板、季节、种子和现场。
4. 换开垦机，按F经过全部计划格；再换回播种机，按F按固定坑位播种。所有目标坑位及初始养分适合后才开始。
5. 驶出范围时只提示下一格并保持开工，不扣资源；缺坑、缺料、换季或作物丢失则暂停。
6. 本轮完成后保留布局、起点、方向和成功索引。整片收获后在播种面板点击“重规划”，检查预览并确认，才能开下一轮。

“重规划”选择当前起点的新方案，不是自动沿用原方案。已有未记录作物会阻止新计划；若预览失败会保留原计划。未确认的预览可旋转；直接F不能跳过确认。

## 配比数据与约束

[aom_giant_layouts](../../mod/Tractor/scripts/aom_giant_layouts.lua)共有111条季节分支：秋21、冬4、春72、夏14；冬季2条养分不平衡仅供参考，可自动执行109条。候选按总种子数、布局ID排序，选择库存足够且通过校验、现场可用的布局；不是最优产值推荐器。随机种子不参与具体作物配比识别。

[aom_block_plan](../../mod/Tractor/scripts/aom_block_plan.lua)检查逐格三类养分平衡、拥挤、季节、逐株家族距离、当前世界坑距和跨格间距；实际土坑位置与初始养分还会在播种前核验。留空位不种；夏季部分组合保留番茄不保证巨大化的提示。

SeedAt仅对指定坑调用farmplantable.Plant，成功后RecordPlanted提交该坑；失败不推进进度，不降级顺序播种。预览分别记录场地错误、模板错误和材料不足，库存够但坑距不兼容时报告MOUNDS_TOO_CLOSE。

## 保存与验证

v3保存布局ID、原季节、起点、旋转、确认及成功索引。确认字段缺省按未确认处理；旧v2不复用已过期索引，保留现场并提示重规划。

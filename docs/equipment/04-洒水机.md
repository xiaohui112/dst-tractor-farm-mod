# 洒水机：设计、操作与实现

基线：0.5.8。按土壤实际缺口补水，以一次原版普通水壶用量为水箱单位；音乐和植物安抚由独立模块处理。

## 参数

| 项目 | 实现 |
|---|---|
| prefab / 类型 | `aom_irrigator` / `irrigator` |
| 配方 | 木板6、绳子4、水球6、冰块12；园艺栏，炼金引擎 |
| 水箱 | 出厂0剂；固定容量400剂，独立于原版水壶容量 |
| 水分剂量 / 上限 | 跟随TUNING，默认每剂25、土壤上限100 |
| 机械耐久 / 维修 | 独立100；燧石每份+10，修理不补水 |
| 结算 / 速度 | 实际浇过一格，油/底盘/机械耐久各1；3世界单位/秒 |

## 操作与补水

挂载后补水，按F经过农田，干地默认一趟用4剂补满；已满不重复浇，停车不重复处理。最后一剂尽量完成当前操作，然后缺水停工，不透支下一格。

驾驶到池塘附近，右键“补满水箱”开始持续5秒的补水，空箱或只缺1剂都耗时5秒。开始时停止农业作业，并把车头转离水源，使后置水箱朝向池塘；软管从水箱伸出、弯向水面，水量随时间增加至400。补水不耗农业燃料、底盘或机械耐久，结束后按F重新开工。

服务端仍核验骑手、真实洒水挂件、pond/watersource标签及3加双方碰撞半径的距离。补水中移动超过0.1、转向超过10°、下车、换挂件、死亡、删除水源/设备、结冰或水源失效都会取消；保留实际吸入水量，清理任务、监听和软管。保存也会取消，读档不会自动继续。水源Use每次成功开始只调用一次，重复点击不创建第二个补水任务。

也可下车手持普通/高级水壶或冰块右键车辆补水。水壶需FiniteUses和fillable，按实际转入剂数扣壶内次数，空壶保留；高级壶不改变每剂效果。冰每份补1剂，仅消耗一份。池塘取水及装水交互不收农业燃料与耐久。

## 按需洒水实现

[aom_irrigator.WaterTile](../../mod/Tractor/scripts/aom_irrigator.lua)判断农田与实时水分，已满返回无变化；有缺口时检查燃料，然后在整格工序内部逐剂循环。每剂先从设备水箱扣1，再调用Soil.Apply并复读，达到上限立即结束。驾驶层对这一整格只结算一次，不应把外层limit从1改4。

[aom_soil_moisture](../../mod/Tractor/scripts/aom_soil_moisture.lua)读取原版IsSoilMoistAtPoint闭包中的实时_moisturegrid，无缓存自建水分表；格中没有独立值时使用世界wetness，并按原版上限钳制。通过AddSoilMoistureAtPoint应用一剂，再核对实际变化。

读取依赖debug.getupvalue及原版闭包结构，无法适配时安全返回MOISTURE_UNAVAILABLE。确认无效果会退回本剂水；已执行但事后无法确认时保守保留水消耗并停工，防止退水后重复得到水分。部分成功也保留真实进度并按格结算。

`aom_farm_work.Water`只转发一次Soil.Apply，供兼容入口使用；整格循环、水箱与补水均在Irrigator模块，不存在三处重复的补满算法。

## 音乐与安抚

Mod设置IRRIGATOR_MUSIC提供三档：开启（播放《兰花草》并安抚）、关闭（不播放且不安抚）、静音（不播放但安抚）。兼容旧true/false配置。取消车辆独立音乐开关、按钮和RPC；旧存档的每车开关不再影响当前设置。

洒水机挂载时显示独立机械耐久表盘与水滴水量表盘，不显示下方状态条。水量数字是剩余剂数，水滴悬停仅显示水量/容量一行。

安抚要求挂洒水机、作业开启、有水、有油及设置允许。服务端每秒调用范围内原版TendTo，范围默认8；同阶段不重复，不额外耗水、油或耐久。该路径与音乐资源/播放是否成功解耦，静音或音频缺失时仍可生效；关闭模式不安抚。开启模式中，每名听者只播放20单位内最近的一辆车，最多一首，音量随距离衰减。

客户端使用原版DoStaticPeriodicTask每0.1秒检测暂停：暂停停止当前声音，恢复后重新核验作业、余水和范围再播放。HUD或听者移除时取消任务并停音；植物安抚仍受服务端模拟时钟暂停控制。恢复会重新播放音轨，当前不保存音轨播放进度。

## 持久化与证据

水量由设备FiniteUses保存，机械耐久保存在独立_aom_machine_uses。新罐空/半/满都显式保存；旧40剂版本保留实际水量，旧空罐不变满；最早未带水量版本的存档沿用此前至多40剂的迁移规则，不因扩容凭空补水。卸载、维修、换驾驶员不重置水量。悬停分别显示机械耐久和水量，客户端通过独立网络字段读取；给水箱加hide_percentage标签，使Show Me不把承载水量的FiniteUses误显示成耐久。

回归：`test_refill_process.py`、`test_irrigator_flow.py`、`test_pond_refill.py`、`test_irrigator_music.py`、`test_music_tending.py`。覆盖满水、零油、剂量、返回、雨水、补给、最后一剂、存档与开关；客户端听感、延迟、喷头对齐仍需实机验收。

0.5.8声音互斥：作业开启且音乐on、有水有油时，只播放洒水音乐，停止本车发动机与工作声；off/mute改播拖拉机音效，mute仍安抚。停工恢复正常怠速/行驶声，缺水、换挂、下车等实时重选。音乐源采样响度对齐原版园艺耕地机约-15.5 LUFS，调用音量1、20距离衰减，仍受游戏音乐音量控制。参考与测量见assets/audio/loudness-calibration.json，原版音频不随Mod分发。

# 开垦机：设计、操作与实现

基线：0.5.6。用途是将可开垦地块准备为能播种的农田，保护已有作物、建筑与邻格土坑；不是无条件清场工具。

## 参数

| 项目 | 实现 |
|---|---|
| prefab / 类型 | `aom_landclearer` / `plow`；兼容旧`aom_plow` |
| 配方 | 木板6、绳子4、燧石16、石砖4；园艺栏，炼金引擎 |
| 机械耐久 / 维修 | 60；地面燧石每份+10，上限60 |
| 作业物料 | 无；原版terraformer适配实体由车辆内部创建 |
| 结算 | 实际改变一格：油、底盘耐久、机械耐久各1；仅拾取或已准备好不计费 |
| 作业速度 | 6×3.75/7≈3.2143世界单位/秒 |

## 操作

1. 上车后右键挂载，给货仓留出收杂物的空间。
2. 普通模式下按F经过空地：铺农田、铲除可清杂物、收掉落、整理3×3九坑。
3. 若使用配比，先用播种机面板预览并确认，换开垦机后按标记经过全部计划格；坑位服从计划，不强制九坑。
4. 有作物、障碍、仓满或清理未完成时检查提示；腾仓、收获或移开障碍后按F继续。
5. 完成配比种植并收获后，必须在播种面板重规划并确认下一轮，换开垦机不会自动重置旧计划。

驶出未完成计划的范围只提示NEXT_TILE并保持开工；驶回目标格可以继续。零耐久自动停工并尝试卸载；无落点时保留损坏设备，移到空地卸载后再维修。

## 实现顺序

[aom_farm_work.Plough](../../mod/Tractor/scripts/aom_farm_work.lua)先检查作物、不可DIG残渣和阻挡，再收纳本格可拾取物；目标农田与坑位已经就绪则结束。

新地调用原版terraformer.Terraform，将目标铺为FARMING_SOIL。回调按原版开垦杂物规则尝试生成残渣，但跳过会破坏邻格既有土坑的位置；不调用原版开垦设备的自毁逻辑。

随后逐项通过Workable.WorkedBy执行原版DIG，收纳本次掉落；有残留则暂停，保留旧坑。清理完成后再次检查保护条件，保留匹配坑位、移除本格不匹配空坑，并按原版占用/邻坑规则创建缺坑。普通坑距4/3，大于默认1.25的邻坑破坏半径；配比模板另验跨格距离。

挖坑期间临时让车辆带NOBLOCK，避免车辆挡住自身目标；真实作物与建筑仍由保护检查阻挡。计划外邻格的手工土坑即使被原版CanTill忽略，也不能被挖坑动作破坏。

## 失败与保护

普通模式不在有作物的格内删坑重整；配比模式由规划器核验已种作物后，仅准备未种位置。不可DIG杂物返回UNCLEARABLE_DEBRIS，残留返回CLEARING_INCOMPLETE，占用返回BLOCKED_MOUND，无法铺地返回CANNOT_PLOW。已发生部分改动会计费一次并保留现场，无农业变化不计费。

掉落散到格边外仍按“本次真实产物”收纳，相邻格原有物品不扫描。仓满保留余量，不能带着阻挡掉落继续挖坑。

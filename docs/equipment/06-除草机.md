# 除草机：设计、操作与实现

基线：0.5.6。用原版DIG清理杂草和园艺残渣，保留真实作物、空土坑与原版掉落。

## 参数与操作

| 项目 | 实现 |
|---|---|
| prefab / 类型 | `aom_weeder` / `weeder` |
| 配方 | 木板4、绳子4、树枝16、燧石12；园艺栏，炼金引擎 |
| 机械耐久 / 维修 | 50；地面燧石每份+10 |
| 物料 | 无；货仓需留出产物空间 |
| 成本 / 速度 | 实际清理一批（含额外刺花）油、底盘、机械耐久各1；约4.2857世界单位/秒 |

上车挂载，按F经过需清理地块。掉落自动进入车仓，停车不重复清理。只捡已有散落物不扣机械成本；没有目标也不收费。满仓时腾空间再按F；无法DIG的杂草/残渣需玩家检查或换兼容工具。

耐久归零停止并尝试卸载；附近无落点则设备留车但不能继续工作。移到空地卸载，步行手持燧石修理，再挂回使用。

## 筛选与批量执行

[aom_farm_work.Weed](../../mod/Tractor/scripts/aom_farm_work.lua)先收纳当前格符合规则的散落物，查找同格杂草及farm_soil_debris。IsFarmPlant优先识别作物定义与farmplantstress，避免其他Mod误加weed标签时铲掉正常作物。

目标必须具有Workable、动作DIG且CanBeWorked。开始批次前预检全部目标，遇到不能清理的实体不先随意处理一半。逐项执行前再次检查实体有效、非作物及动作；普通杂草须仍属本格，额外刺花须仍在原始作业目标的10距离内，以防前一株回调改变后续实体。

每项通过WorkedBy调用原版铲除与掉落，捕获本次生成物后交Container收纳。以工作量减少或实体移除确认真实变化；调用了函数但工作量没减少不收费。

最后复扫本格及原始目标周围的额外刺花，仍有残渣/新生杂草或刺花返回WEEDING_INCOMPLETE；不可DIG目标返回UNCLEARABLE_WEED。已清理一部分时按批结算一次并停工（含额外刺花），无改动不扣油和耐久。它不铺地、不删除/整理土坑、不收割成熟作物。

## 成熟刺针旋花与根须

成熟刺针旋花带farm_plant_defender标签；周边植物被采摘或挖除会触发原版护田广播，生成ivy_snare并延迟攻击，普通骑手的伤害沿原版骑乘链路转给车体。它不是单纯成熟就持续主动攻击路人。

以本格每个原始杂草/残渣的位置为中心，额外扫描原版护田半径10（2.5个地块边长）内的刺针旋花，合并去重后按成熟刺花、其他刺花、普通杂草顺序，在同一批中执行原版DIG及掉落。恰好10距离包含在内；普通杂草仍只清本格，不清周边作物，也不沿额外刺花继续递归扩展。没有本格除草目标时不远程启动清场。

整批先验证可DIG；刺花没有进展或只挖掉部分工作量时立即暂停，不继续普通除草。普通目标执行前再次检查成熟护田刺花，回调新生威胁时停止并等待下一批。已清理部分仍按批结算一次，未变化不收费。刺花移除会取消其待执行攻击并触发原版根须收回。范围外刺花仍可能保护被额外铲除的刺花，或满仓导致批次中断，因此保留反击伤害与破根须兜底，不承诺无伤。

拖拉机服务端的连续更新会破除target为本车或当前驾驶员的ivy_snare，调用原版Health.Kill→death撤销碰撞并播放消退。只处理自身圈，不删除别人的根须、不保护步行玩家；不免疫原版伤害，也不另收农业工序费用。已有圈不再要求下车才能脱困。

## 入仓与故障恢复

本格可拾取物及本次远端刺花/跨格散落的真实产物可入仓，不搬驾驶员已有库存，不跨格扫描相邻旧物。容量不足只收可接纳数量，余量留地面，停止后续杂草。燃烧物、已归属物及巨大产物等遵循[统一拾取规则](../01-Mod核心逻辑玩法设计与技术方案.md)。

原版DIG完成后回调报错，实际清理仍记账并WORK_ERROR停工；真实掉落保留，临时掉落方法会恢复。重新按F按现场残余继续，不重新创造已掉落物品。

## 证据

`test_ivy_defense.py`、`test_weeder_flow.py`18项、`test_work_cargo.py`、`test_audit_regressions.py`，覆盖作物保护、非DIG目标、未减少工作量、满仓、掉落、读档及回调异常。机械循环是耙齿往复，成功后草屑为无农业组件的临时FX；视觉与真实联机仍待实机验收。

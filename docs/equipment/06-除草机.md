# 除草机：设计、操作与实现

基线：0.5.1。用原版DIG清理杂草和园艺残渣，保留真实作物、空土坑与原版掉落。

## 参数与操作

| 项目 | 实现 |
|---|---|
| prefab / 类型 | `aom_weeder` / `weeder` |
| 配方 | 木板4、绳子4、树枝16、燧石12；园艺栏，炼金引擎 |
| 机械耐久 / 维修 | 50；地面燧石每份+10 |
| 物料 | 无；货仓需留出产物空间 |
| 成本 / 速度 | 实际清理一格油、底盘、机械耐久各1；约4.2857世界单位/秒 |

上车挂载，按F经过需清理地块。掉落自动进入车仓，停车不重复清理。只捡已有散落物不扣机械成本；没有目标也不收费。满仓时腾空间再按F；无法DIG的杂草/残渣需玩家检查或换兼容工具。

耐久归零停止并尝试卸载；附近无落点则设备留车但不能继续工作。移到空地卸载，步行手持燧石修理，再挂回使用。

## 筛选与批量执行

[aom_farm_work.Weed](../../mod/Tractor/scripts/aom_farm_work.lua)先收纳当前格符合规则的散落物，查找同格杂草及farm_soil_debris。IsFarmPlant优先识别作物定义与farmplantstress，避免其他Mod误加weed标签时铲掉正常作物。

目标必须具有Workable、动作DIG且CanBeWorked。开始批次前预检全部目标，遇到不能清理的实体不先随意处理一半。逐项执行前再次检查实体有效、同格、非作物及动作，以防前一株回调改变后续实体。

每项通过WorkedBy调用原版铲除与掉落，捕获本次生成物后交Container收纳。以工作量减少或实体移除确认真实变化；调用了函数但工作量没减少不收费。

最后复扫本格，仍有残渣/新生杂草返回WEEDING_INCOMPLETE；不可DIG目标返回UNCLEARABLE_WEED。已清理一部分时按格结算一次并停工，无改动不扣油和耐久。它不铺地、不删除/整理土坑、不收割成熟作物。

## 入仓与故障恢复

本格可拾取物及本次跨格散落的产物可入仓，不搬驾驶员已有库存，不跨格扫描相邻旧物。容量不足只收可接纳数量，余量留地面，停止后续杂草。燃烧物、已归属物及巨大产物等遵循[统一拾取规则](../01-Mod核心逻辑玩法设计与技术方案.md)。

原版DIG完成后回调报错，实际清理仍记账并WORK_ERROR停工；真实掉落保留，临时掉落方法会恢复。重新按F按现场残余继续，不重新创造已掉落物品。

## 证据

`test_weeder_flow.py`18项、`test_work_cargo.py`、`test_audit_regressions.py`，覆盖作物保护、非DIG目标、未减少工作量、满仓、掉落、读档及回调异常。机械循环是耙齿往复，成功后草屑为无农业组件的临时FX；视觉与真实联机仍待实机验收。

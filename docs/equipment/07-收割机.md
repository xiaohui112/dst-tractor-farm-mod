# 收割机：设计、操作与实现

基线：0.5.8。采摘本格成熟或可采收的腐烂农作物，并按原版HAMMER回调拆开巨大农产物，果实与种子进车辆货仓。

## 参数与操作

| 项目 | 实现 |
|---|---|
| prefab / 类型 | `aom_harvester` / `harvester` |
| 配方 | 木板8、绳子4、燧石16、齿轮2；园艺栏，炼金引擎 |
| 机械耐久 / 维修 | 40；地面燧石每份+10 |
| 物料 | 无；货仓存放果实、种子及其他产物 |
| 成本 / 速度 | 实际收割或拆分一格油、底盘、机械耐久各1；约4.2857世界单位/秒 |
| 挂载位置 | 独立实体位于车前，其余五种挂件在车后；侧视及前斜向齿口朝前，父子变换连续跟随，挂载bank按五视图连接点对齐 |

挂载后按F经过成熟、可采收的腐烂作物或已落地巨大产物。收割机不显示下方空配件条，机械耐久与物料/油量等仍在五表盘显示。普通采摘和巨大物拆分在同格只结算一次，不按植株数扣机械成本。15格占满但还有叠堆空间时继续选择性收割，所有堆叠也满时停工，腾空间再F；仅拾取既有普通散落物不收费。

不会采浆果丛等非农作物，不收未成熟作物；不拆建筑、打蜡巨大装饰，不处理由其他库存持有的巨大物品。

## 刺针旋花预检

每批采摘前按当前货仓可接纳的待采植株各自的位置，以原版FARM_PLANT_DEFENDER_SEARCH_DIST（当前10）检查成熟且未燃烧的刺针旋花；发现风险则IVY_THREAT停工，提示先换除草机清理，再收割。没有采摘就不收机械成本；批处理中其他回调产生新的风险时保留已完成部分并停止，按已有变化结算。

收割机保持采摘/巨大产物拆分职责，不自动铲掉邻格杂草。原版plantkin免反击条件保留；未成熟或燃烧中的刺花不触发该安全拦截。挂载收割机期间不再自动破除根须，开工、停工和移动更新均不破圈；已有或新生成的根须保留原版碰撞与伤害，需换除草机处理。仅此收割机例外，其他挂件原有兜底规则不变。

## 腐烂植物分工

收割机负责仍有原版Pickable且CanBePicked的腐烂作物，沿用原版Pick和掉落，普通腐烂株产出腐烂物；不开启作业时不会主动清除，保留原版返生选择。采收会移除原株，也就放弃其本次返生。无法采收但明确腐烂或死亡的农作物残株交除草机处理；开垦机和播种机跳过占用，不负责强制清除。状态判定与满仓腐烂物叠堆共用aom_crop_state，兼容原版farm_plant_killjoy及明确rotten阶段。回归见test_crop_remains.py。

## 普通采摘与产物归属

先按真实空格和堆叠余量筛选：有空格可收新品种；全部占用时，只收主产物已在仓内且堆叠未满的品种，其他作物留地。筛选优先使用plant_def.product，腐烂作物使用spoiled_food，巨大作物按拆分后果实判断。采摘后逐件通过原版CanAcceptCount/GiveItem收纳，种子、其他副产物及溢出部分无法入仓时留地，继续寻找其他可收作物；不提前掷原版随机掉落，不丢弃/复制产物，也不从驾驶员库存挪货。

整仓连堆叠也满时返回CARGO_FULL并头顶提示；只有不匹配品种时继续驾驶、不收费。皮肤或自定义叠堆规则不能安全预测时满格筛选保守跳过。开垦与除草仍按其原有满仓规则暂停。

[aom_farm_work.Harvest](../../mod/Tractor/scripts/aom_farm_work.lua)先收本格散落物，再筛选同格真实农作物和Pickable.CanBePicked。以当前驾驶员作为Pick调用的采摘者，保留原版产量、种子、事件与角色回调。

同步采摘期间临时拦截驾驶员Inventory.GiveItem，只将本次新生成且无归属的产物留在原株位置，由车仓接收；不先合进玩家已有堆叠再搬走，也不扫描拿走玩家原有物品。回调结束无论成功或异常都会恢复原方法。

真实采摘状态变化才算成功。若已经生成产物但onpickedfn报错，将该株原版picked状态持久化，避免重试/读档复制同一产量；保留真实产物，WORK_ERROR停工并结算本格已发生改动。

## 巨大作物处理

巨大产物白名单从原版PLANT_DEFS的product_oversized及其_rotten变体构造，同时要求oversized_veggie标签。只对Workable动作HAMMER且CanBeWorked的对象调用WorkedBy，并以工作量减少或实体移除核验效果。

处理采摘新生成的巨大物时，若原版回调暂将它交给驾驶员，则只将这件本次新产物放回原株位置再拆，不转移无关持有物。之后再次扫描本格无主巨大产物，覆盖回调直接落地和此前已采下的巨大物。

拆分掉落仍由原版回调生成，不人工拼产物清单；本次散到格边的产物可捕获入仓，相邻格旧物不扫描。未拆完、异常或仍有可接纳的成熟目标返回HARVEST_INCOMPLETE或WORK_ERROR，保留现场，已有改动按格收一次费用。因仓内品种不匹配而暂时跳过的目标不算农业失败。

## 保存、动画与验证

货物跟随原版Container保存，机械耐久随配件保存。配比计划不会因收割自动重置；收获后如需下一轮，到播种面板显式重规划和确认。

机械显示保留原图单排收割齿，从左向右循环传动，结果碎叶无额外产物或农业效果。依据：[掉落与采摘适配](../../mod/Tractor/scripts/aom_farm_work.lua)、`test_ivy_defense.py`、`test_harvester_flow.py`21项、`test_work_cargo.py`、`test_review_regressions.py`。已覆盖普通/巨大/腐烂巨大产物、打蜡保护、库存归属、仓满、回调异常与重试；真实多人画面和网络延迟仍待验收。

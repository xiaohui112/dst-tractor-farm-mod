# 收割机：设计、操作与实现

采摘本格成熟或可采收的腐烂农作物。巨大作物可拆分收纳，也可整颗留在田里。

## 参数与操作

| 项目 | 实现 |
|---|---|
| prefab / 类型 | `aom_harvester` / `harvester` |
| 配方 | 木板2、燧石2、齿轮1；园艺栏，炼金引擎 |
| 机械耐久 / 维修 | 200；地面燧石每份+50 |
| 物料 | 无；货仓存放果实、种子及其他产物 |
| 成本 / 速度 | 实际收割或拆分一格油、底盘、机械耐久各1；3世界单位/秒 |
| 挂载位置 | 独立实体位于车前，其余五种挂件在车后；侧视及前斜向齿口朝前，父子变换连续跟随，挂载bank按五视图连接点对齐 |

收割机是前置设备，卸载时保持车身朝向，优先放在车头；车头没有安全空间时保留挂载。

空手左键收割机图标切换模式，切换后停工，再按 F 开始。图标的循环箭头提示可以切换，下方显示当前模式，悬停显示下一档。首次挂载时操作提示显示 4 秒。

| 模式 | 行为 |
|---|---|
| 全部收割（默认） | 采摘成熟或可采收的腐烂作物，按原版锤击掉落拆开巨大产物，包括已经落地的巨大作物。三处库存都满时停工。 |
| 保留巨大 | 采摘成熟的巨大植株，把完整产物留在原株位置，地上已有的巨大产物保持原状。库存满时跳过装不下的普通作物，继续采收完整巨大作物。 |

普通产物依次进入车仓、驾驶员物品栏和已装备背包。每块地皮有实际采摘或拆分时，油、底盘和挂件耐久各扣 1。仅拾取既有普通散落物的作业成本为 0。

不会采浆果丛等非农作物，不收未成熟作物；不拆建筑、打蜡巨大装饰，不处理由其他库存持有的巨大物品。

## 刺针旋花预检

每批采摘前按当前模式下可采的植株位置检查刺针旋花，使用原版FARM_PLANT_DEFENDER_SEARCH_DIST（当前10）。发现风险则IVY_THREAT停工，提示先换除草机清理。批处理中出现新的风险时保留已完成部分，按已有变化结算。

收割机保持采摘/巨大产物拆分职责，不自动铲掉邻格杂草。原版plantkin免反击条件保留；未成熟或燃烧中的刺花不触发该安全拦截。挂载收割机期间不再自动破除根须，开工、停工和移动更新均不破圈；已有或新生成的根须保留原版碰撞与伤害，需换除草机处理。仅此收割机例外，其他挂件原有兜底规则不变。

## 腐烂植物分工

收割机负责仍有原版Pickable且CanBePicked的腐烂作物，沿用原版Pick和掉落，普通腐烂株产出腐烂物；不开启作业时不会主动清除，保留原版返生选择。采收会移除原株，也就放弃其本次返生。无法采收但明确腐烂或死亡的农作物残株交除草机处理；开垦机和播种机跳过占用，不负责强制清除。状态判定与满仓腐烂物叠堆共用aom_crop_state，兼容原版farm_plant_killjoy及明确rotten阶段。回归见test_crop_remains.py。

## 普通采摘与产物归属

按车仓、物品栏和背包的空格与叠堆余量筛选需要收纳的产物。筛选优先使用plant_def.product，腐烂作物使用spoiled_food，全部收割档的巨大作物按拆分后果实判断。采摘后通过原版CanAcceptCount/GiveItem收纳，种子、其他副产物及溢出部分在三处都装不下时留地。

全部收割档在三处库存连堆叠也满时返回CARGO_FULL并头顶提示。皮肤或自定义叠堆规则不能安全预测时满格筛选保守跳过。

[aom_farm_work.Harvest](../../mod/Tractor/scripts/aom_farm_work.lua)先收本格散落物，再筛选同格真实农作物和Pickable.CanBePicked。以当前驾驶员作为Pick调用的采摘者，保留原版产量、种子、事件与角色回调。

同步采摘期间临时拦截驾驶员Inventory.GiveItem，只将本次新生成且无归属的产物留在原株位置，由车仓接收；不先合进玩家已有堆叠再搬走，也不扫描拿走玩家原有物品。回调结束无论成功或异常都会恢复原方法。

真实采摘状态变化才算成功。若已经生成产物但onpickedfn报错，将该株原版picked状态持久化，避免重试/读档复制同一产量；保留真实产物，WORK_ERROR停工并结算本格已发生改动。

## 巨大作物处理

巨大产物白名单从原版PLANT_DEFS的product_oversized及其_rotten变体构造，同时要求oversized_veggie标签。只对Workable动作HAMMER且CanBeWorked的对象调用WorkedBy，并以工作量减少或实体移除核验效果。

处理采摘新生成的巨大物时，若原版回调暂将它交给驾驶员，则把这件新产物放回原株位置。全部收割档随后调用拆分，并扫描本格无主巨大产物。保留巨大档留下原版巨大产物实体，玩家可以手动搬运、称重和打蜡。

拆分掉落仍由原版回调生成，不人工拼产物清单；本次散到格边的产物可捕获入仓，相邻格旧物不扫描。未拆完、异常或仍有可接纳的成熟目标返回HARVEST_INCOMPLETE或WORK_ERROR，保留现场，已有改动按格收一次费用。因仓内品种不匹配而暂时跳过的目标不算农业失败。

## 保存、动画与验证

收割模式随拖拉机保存，旧存档默认全部收割。货物跟随原版Container保存，机械耐久随配件保存。配比计划不会因收割立即重置；收获后重新准备完整九坑，播种机可按现场开始新轮，无需手工确认。

机械显示保留原图单排收割齿，从左向右循环传动，结果碎叶无额外产物或农业效果。依据：[掉落与采摘适配](../../mod/Tractor/scripts/aom_farm_work.lua)、`test_ivy_defense.py`、`test_harvester_flow.py`、`test_work_cargo.py`、`test_review_regressions.py`。已覆盖普通/巨大/腐烂巨大产物、打蜡保护、库存归属、仓满、回调异常与重试；真实多人画面和网络延迟仍待验收。

# 农机 Mod · 方案总览（Index）

## 三十秒读完

1. **原版农场工具共 11 件**（园艺锄、黄金园艺锄、园艺耕地机、洒水壶、邪天翁洒水壶、肥料物品、种子、铲子、锤子、干草叉、水球），对应 5 个核心 Action：`TILL` / `PLANTSEED` / `USEITEM` / `DIG` / `HARVEST`。详见 05 文档。
2. **拖拉机 = 六种挂件**：犁头（耕地机+园艺锄）、播种机（种子）、洒水挂件（洒水壶）、施肥挂件（肥料）、打草挂件（铲子）、收割台（收获）。每件都只是"把原版动作对一格地皮批量执行"。
3. **明确不做**：照料 Happy、自动砸巨大化作物、荆棘藤处理、配比助手、任何数值加速——原版里没有能机械化的对应物。
4. **落地方式**：V1 不做真载具，用"可放置底盘 + 驾驶态"实现，约 11 个工作日。
5. **最优先任务**：拿到本地 DST 的 `scripts/` 源码，把 05 文档里 11 项工具各自的 prefab 与 Action 实现文件找出来——所有实现都以这一步的结果为准。

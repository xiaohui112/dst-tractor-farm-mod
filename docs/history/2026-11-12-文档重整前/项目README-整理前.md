# tractor

《饥荒联机版》拖拉机与六种农场设备 Mod，当前版本 **0.5.1**。

拖拉机和配件制作后直接放置在世界中，配件不能拿进背包。驾驶拖拉机右键配件挂载，右键已挂载配件卸载。挂点独立，**九格仓库全部用于货物与物料**。机械耐久耗尽后停止作业、卸载到地面，修复后可再次挂载。

六种配件已接入独立工作动画：犁铲入土、排种机构、喷头出水、撒肥盘、往复耙齿和单排收割齿从左向右循环传动。土效和水滴优先复用原版资源，缺料、损坏、卸载及下车立即停止作业特效。详见[配件工作动画](25-配件工作动画.md)。

自动行为回归及本机游戏脚本兼容检查覆盖上述状态；底层实体、网络、鼠标输入、音效与画面仍有测试桩，不能替代DST实机及联机验收。

## 安装

将 [Tractor.zip](../../../Tractor.zip) 解压到游戏的 `mods/`，或复制 `mod/Tractor`，确保路径为 `mods/Tractor/modinfo.lua`。在游戏中启用「tractor」，更新后完全退出并重启游戏。联机双方使用同一版本。

运行目录固定为 `mod/Tractor/`；内部 `aom_*` 名称用于存档兼容。旧Windows工具包和历史文档保留溯源，当前操作以本README及[操作流程](09-操作流程.md)为准。

## 制作与维修总表

七种设备统一位于原版「园艺」制作栏，与便便桶、园艺锄、水壶同栏。首次解锁均需炼金引擎（SCIENCE_TWO）；解锁后沿用原版制作规则。制作时显示放置预览，确认位置后生成世界设备，不放入物品栏。

| 物品 | 制作材料 | 机械耐久上限 | 维修 |
|---|---|---:|---|
| 拖拉机 | 齿轮4、电子元件3、木板6、燧石8 | 1000 | 齿轮每份恢复100生命及100作业耐久 |
| 开垦机 | 木板6、绳子4、燧石16、石砖4 | 60 | 燧石每份恢复10 |
| 播种机 | 木板6、绳子4、种子20、齿轮1 | 100 | 燧石每份恢复10 |
| 洒水机 | 木板6、绳子4、水球6、冰块12 | 60 | 燧石每份恢复10；水量独立 |
| 施肥机 | 木板6、绳子4、便便桶1、堆肥6 | 60 | 燧石每份恢复10；肥料独立 |
| 除草机 | 木板4、绳子4、树枝16、燧石12 | 50 | 燧石每份恢复10 |
| 收割机 | 木板8、绳子4、燧石16、齿轮2 | 40 | 燧石每份恢复10 |

六种配件0耐久时仍保留实体，不能挂载；下车手持燧石右键地面配件维修，恢复到正耐久后可以挂载。满耐久不消耗维修材料。修理不恢复水量，也不补充种子或肥料。

拖拉机另有600生命值，与1000次作业耐久分开。空车不吸引普通生物；驾驶员仍按原版规则被索敌，普通近战伤害转给车体，远程、电击、黑暗等沿用原版骑乘例外。拖拉机不能作为战斗坐骑攻击，驾驶面板同步显示车体生命。

生命归零会立刻放下驾驶员、停工，配件和货物落地，原车留下灰暗的损毁残骸并随存档保存，不自动消失或返还材料。下车手持齿轮右键修理，每个同时恢复100生命和100作业耐久，各自封顶；第一份齿轮让残骸恢复100生命，可重新驾驶（仍需有油）。维修保留原有油量、计划和剩余耐久，不补物料；落地配件需重新挂载，货物需重新装入。残骸也可用锤子拆除，回收与正常车相同的半份车体材料。

## 操作

| 场景 | 操作 | 结果 |
|---|---|---|
| 制作设备 | 选择配方后确认绿色放置位置 | 设备落地，不进背包 |
| 上车 | 步行时右键拖拉机 | 原版骑乘，无需牛鞍或驯化；需要有油 |
| 行驶 | 原版移动操作 | 驾驶拖拉机 |
| 挂载 | 驾驶时靠近地面配件并右键 | 提示「挂载」；已有挂件时须先卸载 |
| 卸载 | 驾驶时右键已挂载配件 | 提示「卸载」；停止作业，将配件放到附近空地，人留在车上 |
| 仓库 | 骑乘时点击货仓表盘，或左键车身/人物 | 打开或关闭九格仓库 |
| 下车 | 骑乘时右键车身/人物 | 停止作业、关闭仓库，执行原版下车 |
| 作业开关 | 骑乘时按F | 一次开启，再按一次关闭；松键不关闭 |
| 播种策略 | 驾驶并挂载播种机后，点击配件栏循环箭头图标 | 顺序、随机、配比循环；切换后需重新按F |
| 音乐安抚 | 挂载洒水机时点击配件栏音乐开关 | 同时切换音乐与植物安抚，保持洒水作业；按车辆保存 |
| 加油 | 下车，手持可燃燃料右键拖拉机 | 投入一份燃料 |
| 配件维修 | 下车，手持燧石右键未挂载配件 | 每份恢复10机械耐久 |
| 车体维修 | 下车，手持齿轮右键拖拉机或残骸 | 每份恢复100生命及100作业耐久；两者均满不消耗 |
| 拆除拖拉机 | 下车用锤子拆除 | 配件与货物落地，回收齿轮2、电子元件1、木板3、燧石4；不产生可携带拖拉机 |

配件为固定世界设备，不能左键拾取、进入玩家背包或货仓，只能由拖拉机挂载运输。挂件和车身分别接受点击，不提供独立挂载/卸载或下车按钮；货仓表盘与左键车身共用同一个仓库入口。

卸载优先寻找附近可通行且没有设备、作物占用的位置。若周围没有安全落点，会停工并保留设备，提示驶到空地后再次卸载；设备不会凭空删除。拖拉机损毁时仍保留配件及其剩余水量。

## 驾驶仪表

上车后显示五个原版圆形表盘：车体生命、底盘作业耐久、燃料、配件机械耐久、货仓已用格数。与原版右上角状态栏共用Badge动画及缩放；常驻仅图标和数值，名称、上限、维修方法和操作提示均在鼠标悬停时显示，无配件时耐久牌显示破折号。生命、燃料和机械耐久低于20%时警示。

货仓显示已用格数/9，关闭仓库时仍能同步。9/9表示格子全部占用，同类物品可能继续叠堆；只有实际收纳失败时显示仓满警示。点击箱子表盘或左键车身均可打开/关闭同一仓库，右键车身下车。

下方配件栏按挂载设备显示水量/水条、种子或肥料剩余次数。播种机循环箭头每次点击按顺序、随机、巨大化配比循环；悬停显示当前及下一策略、配比进度，切换后按F重新开始。洒水机音乐开关同时控制声音和植物安抚，关闭不影响洒水；开关按车辆保存，换驾驶员、换配件和读档不会重置。世界配置关闭或资源不可用时开关置灰。小状态灯显示运行/暂停/故障，悬停查看停机原因及车速，不常驻F提示或操作说明。

## 作业效果与消耗

F开启后处理起始地块，随后处理驶入的地块；停车不反复进行同一地块的农业作业。普通地皮为4×4世界单位，普通开垦九坑间距为4/3。无实际变化时不扣燃料和机械耐久。

| 配件 | 一次经过的效果 | 物料消耗 | 机械耐久消耗 | 燃料和底盘耐久 |
|---|---|---|---|---|
| 开垦机 | 铺农田、铲除原版园艺残渣和杂草，普通模式整理3×3九坑；配比模式按规划坑位 | 无 | 实际改动一格扣1 | 每格各扣1 |
| 播种机 | 种入本格全部空坑，支持顺序、随机及季节配比；失败种子退回 | 每成功播种一坑消耗1颗种子 | 每成功播种扣1 | 每颗各扣1 |
| 洒水机 | 读取实时土壤水分，按普通水壶用量补到100，已湿满跳过 | 每剂扣1次水量，每剂默认增加25水分；干地最多4剂 | 实际浇过一格扣1 | 整格各扣1，不按水剂数收费 |
| 施肥机 | 按实际缺口自动选肥、切换肥料，以三类各100为目标；缺少某类时保留缺口并继续 | 按肥料原版每次用量，桶装肥料逐次使用 | 实际施过一格扣1 | 整格各扣1，不按肥料份数收费 |
| 除草机 | 仅清理本格可DIG杂草与园艺残渣，保留作物和土坑 | 无 | 实际清理一格扣1 | 每格各扣1 |
| 收割机 | 采摘本格成熟作物，按原版HAMMER规则拆开巨大产物；保护打蜡装饰 | 无 | 实际收割/拆分一格扣1 | 整格各扣1 |

开垦、除草和收割统一把本格可拾取散落物及作业新掉落收入货仓，收割包含普通果实、种子及巨大作物拆分产物。产量、采摘者及原版作业回调保留，不先合入驾驶员背包，也不搬动其已有物品；格边散落的本次产物仍会收纳，相邻格原有物品不越界拾取。自动叠堆，满仓时保留地面余量、停止后续植株作业并提示，腾出空间后按F继续。仅拾取时不扣燃料或机械耐久；已经完成部分除草/收割时按本格计费一次。

部分作业已经发生时保留真实进度，并按实际作业结算一次；失败或读写异常会停工提示，避免重复消耗。耐久最后一次不会继续透支到下一颗种子或下一地块。缺水、种子耗尽、全部有效肥料耗尽、无油或机械损坏均停止作业，处理后按F继续。

配比播种先生成绿色坑位预览，可旋转并查看范围、种子需求和下一格；点击确认后按F开始，首次直接按F只预览不作业。使用当前季节的已验证模板，需要足量种子及合适地块；原版的季节、水肥、安抚和生长条件仍然生效。

| 水 | 洒水机出厂空罐，默认容量40次普通水壶用量；驾驶到可取水池塘边右键「补满水箱」 |
| 普通/高级水壶 | 下车后把装水的水壶拿在鼠标上，右键拖拉机「补水」；按实际转入量扣壶内水，空壶保留 |

拖拉机出厂油量400，上限800。空驶、停车本身不按时间耗油，只在实际作业时扣油。加油按整份投入并封顶，满油不消耗材料；不足一份的剩余容量不会退回燃料余值。

## 音乐和模型

洒水作业开启、有水和燃料、世界音乐选项及本车音乐开关开启且音频包可用时播放《兰花草》，并由服务端安抚附近可对话作物。范围跟随原版留声机，默认半径8世界单位（约2块地皮），作业开始及每秒检查；植物自身触发原版开心效果。停车时仍可安抚新生长阶段，不重复扣水、油和机械耐久。

车体和六种设备有五视图、八向显示、车轮和车身行驶动画及音效。标准倍率2.5接近成年牛体量；75%、标准、125%、150%四档均补偿人物、服装和帽子的缩放，人物不随车体变大。

## 存档兼容与验证

0.5.1修复配比跨轮隐式换方案、开垦机驶出计划区误停机、预览错误原因和特效/耐久回调异常漏结算；停机原因与参数使用一个网络快照。详见[复查修复记录](27-复查与优化建议.md)。

- 已挂载配件用独立记录随拖拉机保存；地面配件独立保存，避免重复实体。
- 旧存档仓库第一格的挂件迁移到独立挂点，货物保留；旧打包车没有合法展开位置时保留原归属、提示并自动重试。旧v2配比保留现场并提示重新规划，不复用过期坑位索引。
- 六种配件机械耐久、水箱、肥料和种子数量随各自原版组件或独立字段保存，卸载/挂载不重置。
- 仪表新增12项原版控件/RPC流程、2项原生资源核对及2项音乐开关安抚回归；模拟按下/刷新/释放、存档、跨车辆状态、客户端仅网络数据及专服行为。
- 最新386项自动回归包含19项世界设备流程、6项原版承伤与残骸流程、10项除草/收割货仓流程，覆盖直接放置、不可拾取、九格货仓、挂卸权限与距离、六种设备损坏修复复用、独立点击、水量、存档及旧档迁移。

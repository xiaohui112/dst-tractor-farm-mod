# 当前美术接入与重建

当前使用五视图、八向车体和六种配件工作动画。早期三视图/SCML流程保存在[历史记录](history/08-美术接入.md)及13、14号文档，不能覆盖当前成品。

## 运行资源

- 车体：`anim/aom_tractor_chassis.zip`。
- 配件：`aom_attachment_shared.zip`及符号包；六类独立pre/loop/pst状态和成功后的特效。
- 驾驶室共享build/贴图：`aom_tractor_cabin.zip`。
- 四档人物比例补偿：`aom_tractor_driver*.zip`，各自仅包含anim.bin，只加载当前选项和共享包。
- 图标：运行目录只放KTEX和XML，源PNG放在`assets/images/`，禁止把PNG放入Mod的images目录。
- 原版水效等外部build由Mod声明对应原生资源；自定义FX只有视觉，不含农业或库存组件。

## 工具与顺序

Python依赖安装：`python3 -m pip install -r requirements-dev.txt`。图形编译另需ImageMagick及`~/.local/bin/ktech`，音频重建另需FMOD Designer。资源已编译在运行目录，无需玩家安装编译工具。

```sh
# 图标与封面
python3 tools/build_tex.py

# 修改五视图/驾驶室时重建；随后补回六类工作动画
python3 tools/build_directional_art.py
python3 tools/build_attachment_animations.py

# 已有旧的四份完整驾驶包时，可无损转换成共享资源形式
python3 tools/optimize_driver_assets.py

# 发布前严格检查及打包
python3 tools/package_mod.py
python3 tools/package_mod.py --verify-only
```

驾驶重建使用已核验的`Driver-Results.zip`保留原版人物动作，五视图源图保留在`assets/directional-v2/`。优化器先验证四份build/贴图与共享包完全一致，全部通过后才写入；动画字节、动作、帧事件和朝向保持不变。实际体积收益记录在`outputs/driver-optimization.json`，不能用未压缩贴图大小估计ZIP下载收益。

`assets/directional-v2/build.json`、配件动画构建记录和`Driver-Build-Report.json`记录资源SHA。复用原版角色build和皮肤，四档仍做逆向人物矩阵补偿。

## 安装与验收

`tools/install_to_game.ps1`用于Windows安装，macOS可手动复制`mod/Tractor`到游戏mods目录。本次打包不自动修改游戏安装。更新后完全退出并重新启动，联机双方使用同一包。

二进制结构、hash和行为回归不能证明最终画面正确。共享驾驶资源加载、人物皮肤遮挡、配件动作、预览颜色/高度和实际混音仍需DST实机检查。

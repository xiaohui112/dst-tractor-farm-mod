## ① 世界内动画（最重要，不出图是最明显的"没做美术"）

DST 的动画包 = **bank（动画名集合）+ build（图集）**，用 `ktech` 打包成 `.zip`。

### 1.1 `aom_tractor_chassis.zip` —— 拖拉机本体

| 动画名 | 帧数建议 | 说明 |
|---|---|---|
| `idle` | 1~4 帧 | 静止待机，引擎怠速微颤最佳 |
| `work` | 4~8 帧 | 作业时播放，轮胎/开垦机动一下即可 |
| `death` | 1~6 帧 | 耐久耗尽/被打坏，冒烟瘫倒 |
| `idle_packed` | 1 帧 | **打包物品形态**（放在地上/背包预览时用同一 build） |

- **尺寸**：DST 地皮 = 4×4 世界单位；拖拉机建议占 **1 格地皮约 3×2 单位**，画布 256×256 左右，锚点在底部中央。
- **朝向**：代码里没有 `SetFourFaced`，所以**只画一个朝向（正面偏侧）**，靠翻转即可，不要画 4 向。
- **关键**：需要 **`attachment`（车尾）与 `attachment_front`（车头）两个 symbol**（见 1.3），本体图上要留出挂件安装的位置。

### 1.2 `aom_attachment_shared.zip` —— 六种挂件（拿在手里/放地上时）

同一 build 下 6 个动画，**动画名必须严格等于挂件类型名**：

| 动画名 | 挂件 | 建议画法 |
|---|---|---|
| `plow` | 开垦机 | 倒三角铁犁 + 连杆 |
| `seeder` | 播种机 | 料斗 + 下料管 + 轮子 |
| `irrigator` | 洒水机 | 水箱 + 喷口 |
| `fertilizer` | 施肥机 | 撒布盘 + 料仓 |
| `weeder` | 除草机 | 铲齿排 / 旋转刀片 |
| `harvester` | 收割机 | 梳齿 + 皮带 |

- 尺寸建议 **128×128**，锚点底部中央。
- 只需 1 帧（静止就行），拿在手上会显示为"背包图标在手上"。

### 1.3 `aom_attachment_symbols.zip` —— 底盘上挂件的替换 symbol（**最容易被漏掉**）

代码按配件选择挂点：收割机覆盖 `attachment_front` 并显示车头层，其余配件覆盖 `attachment` 车尾层；未装收割机时隐藏车头层。两层都使用 `aom_attachment_symbols` build。
这个 build 里必须包含 **7 个 symbol**（注意是 symbol，不是动画）：

```
empty      ← 没装挂件时显示（可以画一个空挂钩）
plow
seeder
irrigator
fertilizer
weeder
harvester
```

- 画布大小必须和底盘 build 的 symbol 坐标体系一致（建议与 `aom_tractor_chassis.zip` 同尺寸 256×256）。
- **画法**：开垦机、播种、洒水、施肥、除草符号对准车尾挂点。收割机使用单独的车头时间轴，割齿朝前、连接前保险杠，不得尾拖。当前源工程用 `(80,-9)` 偏移和 `scale_x=-1` 镜像原收割机符号，车头层 `z_index=2` 在车身前绘制。

> 💡 **省事做法**：如果不做替换 symbol，把 1.3 改成"直接给底盘出 7 个全套动画"（`idle_plow`、`idle_seeder`…）也行，但要同步改代码。按现在的实现，**三个 build 都得有**。

## ② 物品背包图标（64×64，P0）

进背包后显示的图标，代码通过 `inventoryitem.atlasname + imagename` 指定。

| 图集 | 元素名（= 文件名） | 内容 |
|---|---|---|
| `images/aom_chassis_inventory` | `aom_tractor_item` | 打包好的拖拉机（木箱/包裹感） |
| `images/aom_attachment_inventory` | `aom_plow` | 开垦机的**俯视/侧视小图** |
| | `aom_seeder` | 播种机小图 |
| | `aom_irrigator` | 洒水机小图 |
| | `aom_fertilizer` | 施肥机小图 |
| | `aom_weeder` | 除草机小图 |
| | `aom_harvester` | 收割机小图 |

- 规格：**64×64 PNG，透明背景**，物品需占满画布 80% 左右（DST 图标风格）。
- 交付：两张横排图集（或 7 张单图我帮你拼）。

## 交付格式约定

```
美术交付/
├── anim/
│   ├── aom_tractor_chassis/        ← ktech 工程（bank + build 原始 png）
│   ├── aom_attachment_shared/
│   └── aom_attachment_symbols/
├── icons/
│   ├── inventory/  (7 张 64×64 png)
│   ├── craft/      (7 张 64×64 png)
│   └── modicon.png (512×512)
```

**打包方式**：动画用 [ktech](https://github.com/oblivioncth/ktools)（`ktech anim` 出 `.zip` + `.tex`），图标用 `ktech tex` 或 TEXTool 打成 `.tex` + `.xml`。

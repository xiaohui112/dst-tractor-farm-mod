# 《饥荒联机版》农机 Mod —— 创意工坊竞品调研

> 调研时间：2026-11-10　检索方式：Steam 创意工坊（AppID 322330）站内搜索 + 详情页人工核对
>
> ⚠️ **本文档仅用于避坑，不是功能来源。** 本 Mod 的功能一律以 [05-原版农场工具清单.md](05-原版农场工具清单.md) 为准；这里只回答"创意工坊里有没有同款"。
> 检索词：tractor / farm / farming / plow / seeder / sprinkler / harvest / drone / 拖拉机 / 农 / 犁 / 播种 / 收割 / 灌溉 / 农机

## 一、结论先行

1. **"农机 + 可换挂件"这种玩法结构，创意工坊里没有。** 现有实现全部是"一座机器干一件事"：独立播种机、独立耕地机、独立洒水器、独立施肥机、独立收割机器人，玩家要在一格地皮里摆 4~5 台设备。
2. **最接近的是 `拖拉机`(3748361628)**：它已经有"Z 键切换模式"（翻土 / 播种 / 收割 / 砍树 / 挖矿），但有三个致命差异 —— 模式是**内置菜单**而不是**实体挂件**；耕作是**3×3 粗放**、播的是"该格子里的种子"、没有精细化配比；且它是**载具类 Mod**（月岛祭坛科技、128 金 + 19 齿轮，成本极高，属于后期玩具）。
3. **其他高度重叠的**：`Efficient agriculture` / `Farm Automat`（自动耕地 + 自动播种 + 自动施肥）、`Farm & Field`（3×3 犁地 + 自动收割 + 自动照料 + 各种开关）、`WX-78 Harvesting Bot`（自动收割）、`Betty's Auto Farm Planter`（一键犁地 + 播种 + 巨大作物配比）。
4. **所以我们的差异化不在"能不能自动种田"，而在三个点**：
   - **可装配挂件**（开垦机 / 播种机 / 洒水 / 施肥 / 除草 / 收割机），一个底盘 + N 个挂件，挂件本身是可制作、可拆除、可损耗的物品——**每件挂件都对应一件原版农场工具**；
   - **移动施工**：玩家开车走过去，作业轨迹就是"一条垄"，而不是围绕一个点的半径圈；
   - **舒适度/机械感**：有燃料、有耐久、有坡地、有夜间大灯、有回头率的开车体验，而不是"摆了就走"的挂机设备。

## 四、我们不做的事（避坑清单）

- ❌ **不做数值开关大全**。`Farm & Field` 已经把"夜间生长 / 无限水 / 产出 ×5"写满了，再做同类会被认为是换皮。
- ❌ **不做"摆一台就全自动挂机"**。这类设备（Farm Automat / WX Bot / Auto Sprinkler）已经饱和，且容易让服务器经济崩坏。
- ❌ **不做载具物理系统**。拖拉机(3748361628)是真正的骑乘载具 + 电力接入，物理碰撞与跟随是我们的技术风险区，性价比低。
- ❌ **不抢巨大化作物的"尺寸"判定逻辑**。直接调用原版 `FarmPlant:Harvest` / `farm_plant` 相关接口，尽量不重写巨大化规则。
- ✅ 我们做的是**"操作感 + 机械感"**：让种田从"摆机器"变成"开机械"，这是目前创意工坊的空白。

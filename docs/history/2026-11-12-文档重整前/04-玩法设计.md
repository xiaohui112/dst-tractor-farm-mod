# 0.5.1 玩法设计

当前定位是“驾驶拖拉机，挂载原版农具完成农业重复操作”。保持原版生长、压力、产物与每份物料的效果；提供配比规划、音乐安抚和巨大作物拆分。早期“不做配比/安抚/拆分”的范围已经失效，原文见[历史方案](history/04-玩法设计.md)。

## 玩家循环

炼金引擎解锁七种设备 → 直接放置 → 上车并挂载 → 仓库补料 → 开垦、播种、水肥、除草、收割 → 卸载维修或更换工序。

设备不可拾取，靠车辆挂载运输；九格仓库全部装货和物料。世界配方、材料和数值只维护在[README总表](项目README-整理前.md)，避免多份平衡表漂移。

## 操作原则

- 右键车身/人物上下车，左键车身/人物或货仓表盘开关仓库。
- 右键地面配件挂载，右键已挂配件卸载；不增加重复的挂卸或下车按钮。
- F是持续作业开关，每次上车、换件或切换播种策略后默认停工。聊天/菜单/暂停不接管输入。
- 农业工序只处理当前及驶入地块，停车不重复收费；重新驶入时按实时状态决定是否需要工作。

## 六种工序

| 工序 | 行为与边界 |
|---|---|
| 开垦 | 铺农田、清可DIG杂物、收掉落并整理坑位；保护作物、建筑和邻格土坑 |
| 播种 | 顺序、按槽随机、巨大化配比；每颗成功播种结算 |
| 洒水 | 以原版水壶剂量补实际缺口；水箱40剂、机械耐久独立；池塘骑乘补水 |
| 施肥 | 根据缺口自动选肥和切换；缺某类肥料保留缺口，全部有效肥料耗尽才停工 |
| 除草 | 只DIG杂草和残渣，产物入货仓，保留作物和坑位 |
| 收割 | 原版采摘及巨大产物HAMMER，产物入仓，保护打蜡装饰和持有物 |

音乐安抚随洒水机作业，沿用原版TendTo，不额外扣物料。音乐开关按车辆保存。

## 配比的决策反馈

1. 选择配比策略，点击“预览”，或首次按F生成预览。
2. 绿色标记展示所需坑位；悬停查看作物数量、占地、方向和下一地块中心。
3. 可旋转预览；确认前不改地、不消耗，重复F也不会越过确认。
4. 点击“确认”，换开垦机按F完成准备，再换播种机按F播种。
5. 计划锁定后只指引下一目标格；开垦机和播种机驶出计划区时均保持开工，仅提示驶往计划格，不扣资源。
6. 本轮完成后保留坐标、方向和进度。整片收获后，在播种面板点击“重规划”并确认下一轮；换件、按F或驶到远处均不会自动换配比或起点。已有未记录作物会阻止新计划。

配比帮助处理位置和养分互补，水分、季节、照料及原版压力条件仍然生效，不承诺强制巨大化。

## 失败与恢复

缺料、缺油、机械损坏、仓满或原版回调异常均停工并给出原因；已发生进度和真实消耗保留。清理原因后按F继续。零耐久配件不能挂载或作业，无安全卸载点时暂留车上，驶到空地后卸载维修。

车体600生命与底盘1000作业耐久独立。致命伤放下驾驶员、落货并留下可维修残骸；齿轮同时修生命和底盘。设备耐久、配方与原版每份物料数值本轮不调整。

## 验收标准

以“一整轮农田”验证补给、故障恢复、计划完成和仓库流转，覆盖单人、双人和专服。资源成本与限速应在实际多轮使用后评估；不通过删除原版动作、减少产出或放松保护检查换取性能。

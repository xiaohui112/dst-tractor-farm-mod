# 六种配件工作动画（0.4.1）

六种配件继续使用现有五幅方向图，通过镜像覆盖八向。世界设备各自播放启动、工作循环、停机动画；静止放置与制作预览保留原图。

| 配件 | 机械动作 | 成功作业时的效果 |
|---|---|---|
| 开垦机 | 犁铲向下伸入土中，铲尖周围少量土块遮挡，停机抬起 | 复用原版 `mole_fx / mole_move_fx / move`，经过地块时留下短时翻土迹 |
| 播种机 | 料斗轻震，排种机构转动 | 种子在真实种植成功的坑位落下，不生成额外种子物品或装饰幼苗 |
| 洒水机 | 压力阀转动，水箱保持稳定 | 水滴引用原版 `player_actions_farming` 的 `water` 符号四幅图，按各方向喷头位置循环洒出 |
| 施肥机 | 撒布盘内辐条旋转 | 小颗粒向后扇形洒出，不生成肥料物品、不重复增加养分 |
| 除草机 | 耙齿往复刨动 | 草叶、根须短时散落，原版 DIG 行为及掉落不变 |
| 收割机 | 保留原图的一排齿，沿齿排从左向右循环传动，末端绕回 | 少量碎叶；不增加第二排齿，也不做双排往复剪切 |

## 状态及联机

`aom_attachment_animation.lua` 由服务器控制配件的 `AnimState` 动画和 `_aom_working` 网络状态。显示使用引擎原生动画/实体复制，客户端不自行运行农业结算，不根据本地移动预测生成另一套网络特效。专用服务器同样设置复制状态，无须声音、输入或 HUD。

只有原版农业操作返回实际改动，才创建短时结果特效；无目标、满水、失败等情况不喷水或撒料。水和肥料的显示流最多持续 0.65 秒，新的成功作业续期，同一配件复用一个流实体；停车不重复结算也不会持续喷水撒肥。机械工作循环表示 F 作业开关已开启。

种子、水、肥料耗尽或作业暂停时，立即取消工作循环、删除现有显示实体和续期任务，机械只执行 0.2 秒的收起动作再回待机。最后一份材料仍完成原来的本次农业操作，随后在同一服务器调用内停工。卸载、配件损坏、下车、车体死亡和实体删除也清理特效。保存不记录活动动画、特效或定时器，读档后保持待机。

水流作为配件子实体继承位置和朝向，局部旋转为零，避免转向角度叠加。土迹、落种、草屑留在生成时的世界位置，不随机器拖走。显示实体都没有物理、库存、肥料或投射物组件，且不持久化。

## 构建与验证

```bash
python3 tools/build_attachment_animations.py
python3 tools/preview_attachment_animations.py
PYTHONPATH=/tmp/pylua python3 -m unittest discover -s tools/tests -p test_attachment_animations.py -v
```

构建工具需要 ImageMagick、Pillow、ktech 及本机 DST；`DST_GAME` 可指定含 `data/` 的游戏目录。完整方向素材构建 `tools/build_directional_art.py` 也调用本动画构建步骤。`aom_attachment_water.zip` 只含自己的时间线，原版贴图由游戏读取，不重新分发。原版符号索引及构建 SHA 写在 `mod/Tractor/Attachment-Build-Report.json`。

预览按编译后 ANIM 的实际符号、帧索引及矩阵渲染；水滴使用本机原版纹理，解码副本只留在忽略提交的 `outputs/attachment-preview/`。生成的 GIF 和方向图位于 `assets/directional-v2/`。预览不是游戏截图。

回归覆盖六种动作启停、种子/水/肥料耗尽、真实最后一颗种子与坑位、最后一份水/肥料、失败不触发结果效果、卸载、耐久损坏、下车、车体死亡、移除、存读档、专服和客户端不重复生成效果，以及各方向动画帧和原版资源引用。

尚需 DST 客户端及真实双人联机验收：转向遮挡、喷头对齐、网络延迟和远近切换、末份材料停工后的画面清理。自动测试中的网络与渲染底层仍使用桩，不把它们视为真实联机通过。

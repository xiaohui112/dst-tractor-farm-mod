# 玩法设计书：农机 Mod（纯原版工具机械化）

> **设计原则**：拖拉机的每一个功能，都必须是**原版农场工具的自动化**。不引入原版没有的机制，不参考任何其它 Mod 的功能。原版工具清单见 [05-原版农场工具清单.md](../05-原版农场工具清单.md)。

## 1. 一句话定位

> **拖拉机 = 把原版园艺锄、耕地机、洒水壶、肥料、铲子、收获的重复动作，改成"开着车走一趟"。**

不新增数值、不新增农业机制，只改**操作形态**：从"一件工具一个坑"变成"一台机器一格地皮"。

## 2. 玩家循环

```
科学机器：造园艺耕地机、园艺锄、洒水壶、铲子（原版工具，永远需要）
        ↓
炼金引擎：造底盘（拖拉机）+ 第一个挂件（开垦机）
        ↓
把原版工具装上挂件 → 开着车进农田
        ↓
犁地 → 播种 → 浇水 → 施肥 → 除草 → 收割（开六趟，每趟换一件挂件）
        ↓
作物成熟 → 换收割机 → 收一波 → 巨大化作物留给玩家自己砸
```

## 3. 底盘：拖拉机（不是载具）

| 项 | 数值 | 说明 |
|---|---|---|
| 制作 | 炼金引擎：齿轮 ×4、电器元件 ×3、木板 ×6、燧石 ×8 | 齿轮是原版稀缺资源，作为门槛 |
| 放置 | 作为建筑放下，占 1 格，可被锤子拆回 | 非玩家载具，不参与物理 |
| 驾驶 | 沿用原版骑牛：右键车体上车、右键自己下车；作业由 F 开关控制 | 当前实现以 `09-操作流程.md` 为准 |
| 移动 | 手动驾驶，作业时按挂件类型限速 | 速度及依据见 `28-行驶作业与速度依据.md` |
| 燃料 | 满油800，按实际作业动作扣1 | 可燃型燃料整份加入，封顶不返还，满箱不消耗 |
| 耐久 | 1000，作业消耗，齿轮每份恢复100 | 归零停工，修复后按F继续；健康车体可锤回 |
| 血量 | 600 | 打包保留血量；损毁时下车、回收挂件/物料后移除车体 |
| 夜间 | 没有独立大灯功能 | 不改变原版光照和生长规则 |
| 升级 | 无 | 不做数值成长，保持原版节奏 |

**装备槽**：打开底盘9格容器，第1格放挂件，第2～9格放种子/肥料。

## 4. 六种挂件（对应原版工具）

| 挂件 | 对应原版工具 | 原版动作 | 拖拉机做的事 | 消耗 |
|---|---|---|---|---|
| **① 开垦机** | 园艺耕地机 + 园艺锄 | 生成 Farm Soil Turf、`TILL` | 车前 1 格：无地皮则先铺 Farm Soil Turf，再挖 1 个坑 | 挂件耐久 60 次 / 燧石修复 |
| **② 播种机** | 种子 | `PLANTSEED` | 一趟种完本格空坑，包含边角 | 每颗成功种子扣1燃料、1底盘耐久、1播种机耐久；挂件100次，燧石维修 |
| **③ 洒水机** | 洒水壶 / 邪天翁洒水壶 | 原版土壤加水 | 本格到100即停 | 出厂空罐，容量40次，用装水水壶或冰块补水 |
| **④ 施肥机** | 肥料（粪/鸟粪/堆肥/生长素） | 对土坑 USEITEM | 按所选肥料，对车前坑**当前最缺的那种养分**补一次 | 肥料，每次 1 份 |
| **⑤ 除草机** | 铲子 | `DIG` | 铲掉车前范围内的**杂草**与**园艺残渣** | 挂件耐久 50 次 |
| **⑥ 收割机** | 采摘与锤子 | 采摘 + `HAMMER` | 收割本格成熟作物，同趟拆分巨大产物，掉落走原版 | 挂件耐久40次，每份燧石恢复10次 |

### 挂件的制作（全部用原版材料）

| 挂件 | 配方 |
|---|---|
| 开垦机 | 燧石 ×10 + 木板 ×2 |
| 播种机 | 木板 ×4 + 绳子 ×2 + 草 ×4（内置种袋，8 格） |
| 洒水机 | 木板 ×3 + 绳子 ×2 + 玻璃瓶/水球 ×2（水箱 40 次） |
| 施肥机 | 木板 ×3 + 绳子 ×2 + 草 ×4 |
| 除草机 | 燧石 ×4 + 树枝 ×6 + 绳子 ×2 |
| 收割机 | 燧石 ×8 + 木板 ×6 + 绳子 ×4 |

## 5. 明确**不做**的事（守住"原版"底线）

| 不做 | 原版对应 | 理由 |
|---|---|---|
| 自动照料（Happy） | 牛铃/手风琴/唱片机/友好果蝇 | 照料是角色行为，不是工具能做出来的 |
| 自动砸巨大化作物 | 锤子 | 原版流程是"收获 → 巨大作物落地 → 锤开"；自动化会丢失"巨大作物是战利品/摆件"的玩法 |
| 自动打荆棘藤 | — | 荆棘藤是玩家手动清除的威胁，不归农场工具管 |
| 配比/巨大化助手 | 原版没有 | 玩家自己算配比，拖拉机只负责"把种子种进去" |
| 夜间生长 / 无限水 / 产量倍率 | 原版没有 | 那是改数值，不是机械化 |
| 无人机/农药 | 原版没有农药和病虫害 | 原版农场没有"病虫害"机制（杂草就是杂草），不存在可以机械化的对象 |
| 加速生长 | 原版没有 | 原版只有季节、光照、水分、养分影响速度 |
| 离屏挂机 | — | 原版农场需要玩家在附近才长，拖拉机也是 |

> **此前设想的"农药/病虫害"方向已删除**：原版 DST 的农场没有"病虫害"机制（只有杂草与园艺残渣），没有可机械化的对象。第四、五件挂件改为**施肥机（肥料 USEITEM）**和**除草机（铲子 DIG）**，都是原版真实存在的农场工具。

## 6. 与玩家手动的效率对比（只改变操作，不改变产出）

假设一片 3×3 格的农田（27 个坑）：

| 环节 | 玩家手动 | 拖拉机 | 提升点 |
|---|---|---|---|
| 犁地 | 27 次 `TILL`，每坑走位 | 开车跑过 9 格，每格 1 次作业 | 减少点击与走位 |
| 播种 | 27 次 `PLANTSEED` | 播种机自动补坑 | 减少点击 |
| 浇水 | 每坑 4 次水壶（100 水分） | 洒水机开过去，同格补满 | 减少 4 倍操作 |
| 施肥 | 手动查养分再选肥料 | 按当前最缺的那项补 | 减少试错 |
| 收 | 27 次 `HARVEST` | 开过去一次收一格 | 减少点击 |
| **产出** | 原版 | **原版，完全一样** | 只省操作，不改数值 |

## 7. 模组设置（全部是开关，不调数值）

| 开关 | 默认 | 说明 |
|---|---|---|
| 驾驶速度 | 1x | 0.5x / 1x / 2x |
| 开垦机是否可用燧石直接补耐久 | 开 | 原版园艺锄不能修，这里放松一下 |
| 洒水机上限 | 40 | 同原版水壶 |
| 是否允许开垦机在普通地皮上铺 Farm Soil Turf | 开 | 关掉则只能在已有农田地皮上挖坑 |
| 收割机：巨大作物 | 无开关 | 按原版采摘后锤开，不改写巨大化判定和产量 |
| 显示格内养分/水分条 | 开 | 只是 UI 显示，不改数值 |

## 9. 卖给谁（创意工坊页面）

- 「把原版农具装到拖拉机上去」——六个挂件就是原版六类农场工具。
- 「不做数值，只做操作」——明确写"产量与原版一致，不加成长加速"。
- 三张 gif：犁地成垄、播种机补坑、洒水机浇水。

## 10. 路线图

- **V1**：底盘 + 六挂件 + 开关 + 联机同步。
- **V2（谨慎）**：如果玩家强烈要求，再做"巨大化作物收割+锤开"的二档开关，默认关。
- 不做 V3 数值成长线。

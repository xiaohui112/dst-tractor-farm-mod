## 三、工具链安装（已在本机完成）

`ktech` / `krane` 没有官方 macOS 预编译包，需从源码构建：

```bash
brew install cmake pkg-config imagemagick

curl -sL https://codeload.github.com/dstmodders/ktools/tar.gz/refs/tags/v4.5.1 -o k.tgz
tar xzf k.tgz && cd ktools-4.5.1

# 新版 CMake 对老 CMakeLists 有策略限制，必须加这个参数
cmake -DCMAKE_POLICY_VERSION_MINIMUM=3.5 -DCMAKE_BUILD_TYPE=Release .

make -j8
cp ktech krane ~/.local/bin/     # 注意产物在源码根目录，不在 build/
```

验证：`ktech --version` 与 `krane --version` 均应输出 `4.5.1`。

## 六、美术包里的已知注意事项

- 美术包自述：车体在 256×256 画布中只占右下角，底部距画布边缘 16px。编译后若发现"浮空"，需要在 SCML 里调 pivot 或在游戏里调 `SetScale`
- `attachment` 车尾层 `z_index=0`，`body` 为1；收割机独立使用 `attachment_front` 车头层 `z_index=2`。收割机通过 SCML `(80,-9)` 偏移及水平镜像连接车头，其他配件保留车尾挂点
- 原始美术包的 `validation.json` 是出图时记录；后续Windows编译与结构回读见 `assets/animation/build.json` 及驾驶构建记录。游戏内验证仍未完成。

# 0.2.10 骑乘池塘补水

挂载洒水机后，驾驶拖拉机靠近未结冰、可取水的池塘，右键池塘选择「补满水箱」。无需下车、水壶或冰块，一次补满当前洒水机的实际容量，默认40次普通水壶用量。

普通池塘、蚊子池塘和洞穴池塘沿用原版 `pond`、`watersource` 标签及 WaterSource 可用状态；结冰后原版撤销取水标签时不提供动作。水箱已满时也不提供重复动作。海水和没有池塘标签的其他水源不纳入本次入口。

服务端执行前核对当前骑手、拖拉机、实际安装的洒水机、水源可用状态，以及动作距离和双方碰撞半径。调用原版水源 Use 回调，通过现有水箱接口增加水量并同步到面板，不消耗燃料、底盘耐久或任何携带物。

动作可在骑乘中执行，使用原版角色和客户端的短动作状态，保留驾驶关系。补水不改变 F 作业开关；此前因空水箱停工时，补满后按 F 继续。水壶和冰块的下车补水方式保留。面板及空水箱提示更新为直接在池塘取水。

新增11项流程回归，执行实际 Mod、原版 WaterSource、Rider、Container、FiniteUses 和存读档方法，覆盖右键提示、三种池塘、满水箱、距离、结冰与解冻、驾驶员与挂件校验、客户端无组件提示、F 状态、存档和中英文反馈。完整自动回归270项；地图、实体、网络与状态执行底层仍为测试桩，更新后需完全重启游戏进行实机验收。

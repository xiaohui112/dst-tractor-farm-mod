# 0.2.3 六项修复

本版安装包已包含编译完成的五视图、八向驾驶动画、引擎音效和脚本，不需要在 Windows 重新出图或编译。

## 玩家操作

1. **比例**：默认使用以成年牛为基准的车体体量，地面、骑乘及六种挂件共用一个倍率。人物合成比例由旧版的 0.24 调至 0.85，避免驾驶室里的人物过小。旧版 2～4 倍配置回到新标准，也可选 75% / 125% / 150%。
2. **朝向**：拖拉机与每个挂件都有前斜、侧面、后斜、正前、正后五张独立贴图；左右镜像覆盖八向。正前和正后的行驶动作也已补齐。
3. **装备与物料**：驾驶面板点「装备与物料」，打开独立九格窗口。左上为挂件，另外八格放种子/肥料，显示真实物品及堆叠数；水存在洒水机里，在面板显示余量。仓库不受整合背包设置影响，驾驶中保持打开，下车关闭。
4. **拆下挂件**：驾驶面板与仓库底部都有按钮。拆卸立即停工，挂件退回背包；背包满就掉到人物旁边，种子/肥料留在车内，水量跟随卸下的洒水机。地面拆卸须先打开附近拖拉机的仓库。
5. **行驶视听**：所有配件共用带轮毂旋转、车身悬挂起伏和挂件抖动的行驶动画。上车有怠速声，移动切换行驶声，移动作业叠加机械声，没油或下车停止引擎声。
6. **标准九宫格**：普通开垦按 4/3 间距生成 3×3 九个可播种坑。原版会打坏 1.25 距离内的邻坑，旧版间距 1 导致后挖的坑破坏前面的坑。新间距在相邻地皮之间也保持一致。巨大化配比仍按其独立布局和预留空位规则处理。

F 仍为持续作业开关，松键后继续，再按一次停止；缺种子、水、肥料时停工并在人物头顶提示，补料后按 F 续作。燃料、耐久及作物保护检查继续生效。

## 素材与构建

- `assets/directional-v2/*-five-views.png`：imagegen 生成的七张透明五视图源图，原图保留。
- `sprites/`：按透明分隔切出的五向精灵；`rig/`：可编辑 SVG 轮毂运动层及其栅格输出。
- `seat-layout.json`：当前人物座位与比例；旧版 `assets/driver/seat-layout.json` 保留用于恢复旧人物时间线的坐标。
- `build.json`：五个动画包的 SHA-256、方向位、1229 条驾驶动作/方向组合与 12 帧行驶相位。
- `assets/audio/tractor_*.wav`：自行合成的怠速、行驶、作业循环，各 4 秒，44.1 kHz 单声道。
- `assets/audio/fmod/aom_tractor_sfx.fdp` 及 `tractor-build.json`：FMOD 项目与编译记录；运行目录含真实 FEV/FSB 音频包。

美术重建需 Python 3、Pillow、ImageMagick，以及 `~/.local/bin/ktech`。人物时间线来自已核验并入库的 `Driver-Results.zip`，不固定角色 build 或皮肤。

```bash
python3 tools/build_directional_art.py
python3 tools/preview_vehicle_motion.py
python3 tools/package_mod.py
```

声音重建使用 FMOD Designer 命令行。Windows 直接传 `--designer`；macOS 使用 Wine 时增加 `--wine`：

```bash
python3 tools/build_tractor_audio.py --designer /path/to/fmod_designercl.exe --wine /path/to/wine
```

`tools/package_windows_animation.py`、`tools/package_windows_driver.py` 与两个已有 Windows ZIP 保留旧版 SCML 工作流，当前五视图请使用上述重建入口。

## 验证结果与边界

236 项回归通过，包括真实上下车组件、F/RPC、九格容器、驾驶中开关仓库、拆卸回背包/满包落地、物料保留、三块相邻地皮的 27 个坑，以及原版邻坑破坏方法。

资源测试核对五方向帧、八向 `mount/dismount/idle_loop/run_*`、轮毂相位与车身位移、人物比例恢复、三种真实 PCM 音效、音效状态切换与停止。BILD/ANIM/KTEX 资源另由 krane 回读，安装包逐文件与源码及清单比对。

本机未安装 DST，自动检查使用引擎/地图/网络/声音表面桩。尚未完成真实客户端画面、驾驶室人物遮挡、实际音量与联机视听同步验收；比例和视觉效果仍需以游戏内画面为准。

完整行为回归386项；0.5.0新增26项审查/规划/发布回归，0.5.1追加11项二次复查回归。原有一个完整流程检查覆盖109套配比×4种旋转。原版CollapseSoilAtPoint参与挖坑和新田杂物逻辑，不再用空函数代替。现有骑乘、货仓、承伤、仪表、音乐、动作、动画和安装包验证继续运行。

| 范围 | 验证内容 |
|---|---|
| 配比 | 养分/家族/季节、当前坑距与跨格间距、四方向开垦/播种、旧v2计划安全停用 |
| 设备 | 损坏后卸载受阻、零耐久重开不作业、物料/水量/机械耐久分离 |
| 异常 | 操作前异常不扣费，部分采摘/挖掘/挖坑后异常按真实进度结算并停工，恢复临时方法/标签 |
| 防重复 | 已产出但采摘回调报错时保存picked状态，重试不复制产物 |
| 拾取 | 新掉落散到格边仍入仓，邻格原有物保留，仓满保留余量和进度 |
| 迁移 | 无落点时保留原归属，保存/再读档仍可重试，最终仅展开一台车及一份货物 |
| 规划 | 预览/旋转/确认不改地不扣料，确认重查库存/建筑，权限/保存/预览清理和下一格 |
| 同步 | 客户端仅读网络状态，在不同语言下显示原因，仓满判断不依赖文案 |
| 发布 | 缺Lua依赖失败，macOS目录自动识别，发布禁止跳过，失败不替换旧包 |

严格自检要求0失败、0警告、0跳过；逐项结果和测试执行数记录在`outputs/selfcheck-validation.json`。图形/输入/网络表面仍部分为桩，自动通过不等于实机通过。

## 打包与一致性

```sh
python3 -m pip install -r requirements-dev.txt
python3 tools/selfcheck.py --release
python3 tools/package_mod.py
python3 tools/package_mod.py --verify-only
```

`package_mod.py`自动执行严格发布检查，通过后原子生成`Tractor.zip`。包内`INSTALL-MANIFEST.json`记录64个运行文件的SHA-256和长度，源码/ZIP/清单逐文件核对，拒绝重复、过期和额外条目。最终归档SHA-256、文件数与CRC结果记录在`outputs/install-validation.json`。

本轮只重新生成项目安装包，没有覆盖游戏mods目录；旧`game-install-validation.json`不是本轮安装证明。

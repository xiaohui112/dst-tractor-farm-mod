# 0.5.1 实施与验收计划

早期搭建计划已归档至[历史版本](history/03-实施计划.md)，当前任务状态见[研发清单](TASKS-整理前.md)。

| 阶段 | 交付 | 验收 |
|---|---|---|
| 约束修复 | 重算109套布局、跨格间距、邻坑保护 | 原版地图破坏逻辑下四方向开垦及完整播种 |
| 生命周期修复 | 零耐久拦截、异常结算、掉落追踪、迁移重试 | 按故障真实触发点注入，验证资源、归属、现场和重试 |
| 结构优化 | 配件定义、作业结果、原因码 | 六类设备共享检查，客户端不依赖提示文字或服务端组件 |
| 交互优化 | 配比预览、旋转、确认、下一格 | 规划不改地不扣料；权限、库存变化、保存与预览清理 |
| 二次复查 | 完成计划不隐式重置、NEXT_TILE统一、错误原因与异常结算 | 跨两轮流程、驶出/返回、特效及耐久回调故障、原因与参数单载荷 |
| 资源优化 | 驾驶共享build/贴图 | 原动画逐字节不变，保留全部四档和八向 |
| 发布 | 严格自检、原子打包、清单核对 | 无失败/跳过/警告；安装包与运行目录逐文件一致 |
| 实机验收 | 客户端、双人、专服 | 仍待执行；不可用单元测试替代 |

实机重点：绿色预览的渲染与遮挡、界面缩放、独立配件点击/跟随、共享动画包加载、旧档迁移受阻后的自动展开、断线/死亡与两个驾驶员切换。联机双方必须使用同一版本并完全重启客户端。

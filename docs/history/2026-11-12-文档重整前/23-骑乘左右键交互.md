# 0.2.11 骑乘左右键交互

坐在拖拉机上时，左键点击车身或人物开关九格仓库，右键点击车身或人物直接下车。仓库打开、手上拿着物品、无挂件或没油时也保持这套操作。下车先停止作业并关闭仓库，再沿用原版骑乘下车动画。

移除驾驶面板和仓库窗口上的独立开仓、关仓、下车按钮，面板保留一行左右键文字提示。播种策略与拆下挂件入口保持原有用途。

技术上只包装原版 PlayerActionPicker 的左右键方法，只在点击自己或当前拖拉机时介入，并继续使用原版动作过滤、BufferedAction 与 DISMOUNT。左键仓库动作是骑乘有效的即时动作，服务端核对目标与骑手归属，使用原版 Container 开关接口。右键不再被开仓状态下的 RUMMAGE 抢占。

点击池塘、其他实体、步行和其他坐骑继续走原处理；骑乘时右键池塘补水保留。原版动作过滤仍可阻止暂停、幽灵等状态的输入。已有内部 RPC 接口保留兼容，不再提供独立按钮。

完整行为回归284项。更新4项原有仓库/下车/UI流程，新增6项鼠标流程，执行本机原版 PlayerActionPicker、BufferedAction、Rider 和 Container，验证持物点击、动作过滤、池塘交互、作用范围、客户端无服务端组件与英文提示；原有忙碌状态、没油空车、归属、行驶持续开仓、即时关仓下车和按钮移除也覆盖。

实体、网络和实际输入设备仍为测试桩，安装后需完全重启游戏进行实机验收。

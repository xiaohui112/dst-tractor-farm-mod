# 拖拉机：设计、操作与实现

基线：0.5.8。拖拉机承担驾驶、独立挂载、15格货仓、资源结算和生命周期；农业工序由挂件分发。跨设备作业规则见[核心方案](../01-Mod核心逻辑玩法设计与技术方案.md)。

## 参数与制作

| 项目 | 当前实现 |
|---|---|
| prefab | `aom_tractor_chassis` |
| 配方 | 齿轮4、电子元件3、木板6、燧石8；园艺栏，炼金引擎首次解锁 |
| 生命 / 作业耐久 | 600 / 1000，分别维护 |
| 初始 / 最大油量 | 400 / 800 |
| 货仓 / 挂件 | 原版Container15格 / 独立挂点一个 |
| 空驶速度 | 3世界单位/秒；空驶、作业均为原版人物初始跑速50% |
| 模型 | 基础倍率2.5，配置相对75%、100%、125%、150%；驾驶人物有逆向比例补偿 |

货仓单排15格，逐格与人物栏前15格对齐，包括5/6、10/11之间的分组间距；打开时及原版布局重建后重算槽位和背景宽度；状态图标位置不随开关货仓变化。取消原货仓顶部标题与说明，原版槽位继续处理拖放、叠堆与快捷转移。货物仍保存在车体中，原版背包同时保留。旧档前15格原样恢复，第16格合并堆叠或放空格，仍放不下的余量完整落在车旁。

## 具体操作

1. 选择配方并确认绿色放置位置，世界中生成整车。
2. 右键有油且未损毁的车上车，沿用原版移动控制；无需鞍具、驯化，不接受牛鞍。
3. 驾驶到地面配件附近右键“挂载”。换件先右键已挂配件“卸载”，人留在车上。
4. 左键自己/车身，或点击货仓表盘开关仓库；右键自己/车身下车。下车关仓并停工。
5. 按F开关持续作业。挂卸、换播种策略、上下车后需重新开启。
6. 驾驶时拿起燃料左键燃料图标加油，拿起齿轮左键生命或底盘图标分别修理；满值不消耗。右键挂件图标卸载，拿起燧石左键该图标修理已挂件；驾驶时也可手持燧石右键地面配件修理。

配件不能拿进背包；本车仅能挂一件，不能抢走其他车的配件。挂载服务端距离为5加双方碰撞半径，并核验当前骑手和正机械耐久。卸载即时执行，不改变车身朝向；收割机在车头、其余配件在车尾半平面半径3～18的候选点寻找可通行且没有阻挡的位置；无安全位置保留挂件。损毁/移除的强制释放可退回当前附近位置，优先保证实体不丢失。若挂件被控制台或其他工具直接删除，车辆立即停工、清空挂载与相关仪表，允许直接换挂。旧版本留下的失效引用在读取、挂卸或保存时清理，不会凭空补回已删除物品。

工作区快速修复：上车沿用原版动作时间线，但在拖拉机上跳过第14帧坐骑叫声，保留其他动作音和发动机声音；此修复已收录0.5.8，实际听感继续实测。

## 驾驶仪表

血量保留原版红色底图，底盘/燃料/货仓/配件使用中性底图，各表盘下方统一纸面数字牌。货仓排在配件左侧，数字为含堆叠的物品总数；液面与悬停中的格数仍表示15格占用情况。六种挂件均取消常驻下方状态条。播种空手左键最右配件表盘直接循环切换策略，原切换方块移除，配比模式自动匹配九宫格方案，无需规划确认；洒水追加水滴表盘；施肥物料统一从货仓数量及悬停查看。与综合状态显示共用原版Badge时，仅清理本模组表盘上的重复数字底板，不修改玩家原状态栏。

悬停仅展示关键数值：生命、底盘、燃料各一行；其他挂件名称与耐久两行，播种机为名称、耐久、当前策略三行；货仓占用格数与含堆叠总数两行。操作说明、车速、异常原因及肥料分类不再追加。维修、补油和失败结果在人物头顶反馈；空手左键播种机图标直接切换策略，拿起物品时点击优先尝试修理。

工作区喊话继续修复：跟随headbase零偏移，间距只用屏幕偏移，避免驾驶倍率放大，下车恢复原定位。死亡动画使用原美术交付death.png，不再复用收纳态半尺寸贴图，保持所选车体倍率；仅有单张残骸图供五个方向共用，维修后恢复正常五视图。

0.5.8之后工作区再修复（未发布）：客户端依据同步骑手设置喊话锚点，不再依赖只存在服务端的驾驶动画Lua标记；骑手同步、上车和首句ontalk立即刷新。四档模型共享56屏幕单位间距。人物侧向使用原版真正侧脸，正后方使用背影，行驶、待机和说话保持同方向；五种后挂件正面完全被车身遮住，卸载到地面后照常可见，收割机不受影响。无挂件表盘中央留空，重新挂件恢复对应图标。

## 补给与修理

悬停车体时显示燃料数值，手持燃料或齿轮、切换加油/修理/存放提示时仍保留油量。

燃料必须有有效fuel组件，fueltype为空或BURNABLE且fuelvalue为正有限数；以该物品实际fuelvalue增加油量，投入一份并封顶800，超过剩余容量的部分不返还。

工作区新增行驶耗油，尚未打包安装：每移动4距离扣1燃料，农业结算另扣；无挂件、关F或缺料停工后继续开车也收费。待机、原地转向和静止池塘取水不扣行驶油量。服务器每0.1秒按骑手位置结算，落座定位和大于16距离的传送只重置起点，下车前补结最后一段；下车、死亡和删除时取消任务。油尽停止作业和行驶，速度零同步给客户端，仍允许下车或点击燃料图标加油，加油恢复行驶但不自动恢复F作业。小数油量正常保存。

驾驶时图标维修分离：生命图标每份齿轮只增加100生命，底盘图标每份只增加100作业耐久，各自封顶，另一项不变。步行齿轮右键车体或残骸仍同时恢复两项。底盘耐久归零禁止农业作业，但不等同于生命归零。六种配件均可在驾驶时拿起燧石左键挂件图标维修，或驾驶/步行手持燧石右键地面配件，每份+10且不补水。普通对车使用燧石仍不修理、不消耗；仪表请求由服务端核验当前骑手、请求车体和鼠标持有物品后执行。

仓库允许种子、肥料和普通货物，不保留“第一格挂件槽”。装料入口按容量移动可接纳数量；接收失败尽量退回原库存槽位，无法退回时落在来源位置，不隐藏吞物。

## 刺花与根须脱困

成熟刺针旋花会对附近的采摘/挖除行为反击。除草机优先清理，收割机先做危险预检。车体定期检查针对本车/当前驾驶员的ivy_snare，调用原版死亡回调破圈并撤销碰撞；保留原版伤害和短暂受击硬直，不处理他人的根须或步行玩家。

## 承伤、残骸与拆除

车体带Health、Combat、Rideable，Combat禁止坐骑攻击。驾驶员仍由原版生物索敌，普通近战经原版骑乘链路转给车体；远程、电击、黑暗等遵循原版例外。停放空车不作为普通战斗目标。

生命归零立即下车和停工，挂件与货物落地，保留灰暗且可保存的残骸，不自动返还材料或消失。齿轮原地修复；有油且生命恢复后可再驾驶，货物与挂件需要重新装回。油量和计划保留。

锤拆需要4点HAMMER工作量，掉落齿轮2、电子元件1、木板3、燧石4并删除车体，不生成打包车。正常锤拆若挂件没有安全落点，会保留车辆等待重新处理。

## 实现与存档

[prefab](../../mod/Tractor/scripts/prefabs/aom_tractor_chassis.lua)构造网络变量，再在主模拟端添加健康、骑乘、移动、底盘FiniteUses、Workable、Container和AttachmentStore；客户端不添加农业组件。

原版Rideable/Rider和SGwilson处理上下车；[SGaom_tractor](../../mod/Tractor/scripts/stategraphs/SGaom_tractor.lua)提供坐骑实体状态。驾驶外观通过[aom_driver_visual](../../mod/Tractor/scripts/aom_driver_visual.lua)覆盖驾驶bank与驾驶室build，保留角色原build、皮肤和衣帽；独立挂件驾驶时以骑手为父节点，停放时以车辆为父节点，连续继承移动与转向；收割机在前，其余在后。工作区现按五视图连接点对齐挂载bank，取代统一大距离；卸载恢复地面bank。六种配件移动作业时均从左侧细烟筒口排烟，定位随视图、转向和悬挂动画更新。

OnSave保存油量、挂件独立记录、策略与计划，原版组件保存生命、底盘耐久及货仓。挂件随车保存时不再独立持久化，恢复失败则落地。读档保持停工；旧仓库内挂件迁移到独立挂点，旧打包车受阻保留原归属并自动重试。

# 开垦机：设计、操作与实现

基线：0.5.8。用途是将可开垦地块准备为能播种的农田，保护已有作物、建筑与邻格土坑；不是无条件清场工具。

## 参数

| 项目 | 实现 |
|---|---|
| prefab / 类型 | `aom_landclearer` / `plow`；兼容旧`aom_plow` |
| 配方 | 木板6、绳子4、燧石16、石砖4；园艺栏，炼金引擎 |
| 机械耐久 / 维修 | 100；地面燧石每份+10，上限100 |
| 作业物料 | 无；原版terraformer适配实体由车辆内部创建 |
| 结算 | 实际改变一格：油、底盘耐久、机械耐久各1；仅拾取或已准备好不计费 |
| 作业速度 | 3世界单位/秒（人物初始跑速50%） |

## 操作

1. 上车后右键挂载，给货仓留出收杂物的空间。
2. 普通模式下按F经过空地：铺农田、铲除可清杂物、收掉落、整理3×3九坑。
3. 普通与配比播种均先准备九宫格坑位；开垦不再读取旧播种规划，不使用错位六边形。
4. 新地块有植物或固定障碍时整格跳过；已有农田跳过植物占用坑位，其他空位继续。仓满或清理回调未完成仍需处理后按F继续。
5. 收获后重新准备空坑即可播种；播种机自动选择下一轮，无需规划确认。

驶出未完成计划的范围只提示NEXT_TILE并保持开工；驶回目标格可以继续。零耐久自动停工并尝试卸载；无落点时保留损坏设备，移到空地卸载后再维修。

## 实现顺序

[aom_farm_work.Plough](../../mod/Tractor/scripts/aom_farm_work.lua)先检查作物、不可DIG残渣和阻挡，再收纳本格可拾取物；目标农田与坑位已经就绪则结束。

新地调用原版terraformer.Terraform，将目标铺为FARMING_SOIL。回调按原版开垦杂物规则尝试生成残渣，但跳过会破坏邻格既有土坑的位置；不调用原版开垦设备的自毁逻辑。

随后逐项通过Workable.WorkedBy执行原版DIG，收纳本次掉落；有残留则暂停，保留旧坑。清理完成后再次检查保护条件，保留匹配坑位、移除本格不匹配空坑，并按原版占用/邻坑规则创建缺坑。0.5.22起，新九宫格偏移由`aom_farm_grid.lua`统一定义为±1.3125及0，可被二进制浮点精确表示；同格坑距1.3125、跨格最近坑距1.375，均大于默认1.25的邻坑破坏半径。旧坑位仍按实际位置参与播种；需要新坑位时，在收获后的空田重新开垦。已有作物保持原位，配比模板另验跨格距离。

挖坑期间临时让车辆带NOBLOCK，避免车辆挡住自身目标；真实作物与建筑仍由保护检查阻挡。计划外邻格的手工土坑即使被原版CanTill忽略，也不能被挖坑动作破坏。

## 失败与保护

已有农田只整理不影响植物的坑位，保留植物附近旧坑，也保护邻格植物；新地有植物不铺地。杂草及其他植物保留，由除草机处理。开垦统一生成九坑，自动播种独立核验现场与余料；未准备好不算完成，也不虚增已种数量。占用、不可DIG障碍及不可铺地不终止连续驾驶；清理回调未完成、仓满、资源耗尽和异常仍停工。实际改动一格计费一次，无改动或重复经过不计费。

掉落散到格边外仍按“本次真实产物”收纳，相邻格原有物品不扫描。仓满保留余量，不能带着阻挡掉落继续挖坑。

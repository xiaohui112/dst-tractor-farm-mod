## 第一次使用

七种设备均在原版“园艺”栏，首次解锁需要炼金引擎。

1. 制作拖拉机和开垦机，确认放置位置。
2. 右键有油的拖拉机上车，靠近开垦机并右键挂载。
3. 按F开启，驶过空地铺农田并准备九坑；再按F关闭。
4. 右键已挂配件卸载，换播种机，把种子放入货仓，再按F播种。空手左键最右侧播种机表盘直接切换策略，悬停显示名称、耐久和策略；配比模式自动选择九宫格方案，无需确认。
5. 后续换洒水、施肥、除草、收割设备。货仓满或缺料时处理原因，再按F继续。

作业开启后松F不会关闭；停车不重复农业作业。换件、下车和切换播种策略会停工。原版移动操作驾驶，左键车身/自己或点击货仓表盘开关仓库，右键车身/自己下车。

## 补给、维修与损毁

- 油量初始400、上限800。驾驶时拿起有效燃料左键燃料图标补给，也可下车手持燃料右键车身；每份按原版fuelvalue补充，满油不消耗。
- 种子和肥料放任意货仓格；装对应设备后，也可下车手持物料右键车身装料。
- 洒水机出厂空罐。驾驶到可取水池塘旁右键“补满水箱”；下车可用装水的普通/高级水壶或冰块补水。
- 右键挂件图标卸载。驾驶时拿起燧石左键挂件图标，每份修复10挂件耐久；地面挂件也可驾驶或步行手持燧石右键修理，满耐久不消耗，不补水或物料。
- 驾驶时拿起齿轮左键生命图标，只恢复100生命；左键底盘图标，只恢复100底盘耐久，各消耗1份、各自封顶。步行齿轮右键车体/残骸仍同时修复两项。

没有安全卸载点时保留设备，驶到空地再卸载。车体生命归零强制下车、落货与配件，留下可保存、可修理的残骸；锤拆返还齿轮2、电子元件1、木板3、燧石4，不生成便携打包车。

## 巨大化播种

先用开垦机准备九宫格坑位，装播种机并切到“巨大化”，按F自动规划并播种。服务器按实际坑位扫描最多64块四边连通的有效地皮，支持L形、凹形等范围；不完整或被占用的地皮不作为连通桥梁。农田索引只是缓存，重启后也可从现场重新发现完整九宫格。

新方案只检查应季种子库存、同族数量与距离、坑距和拥挤条件，不读取养分，也不以免施肥为配比限制。数量优先，数量相同时优先采用更多种能满足同族条件的种子，再尽量压缩占地；排列整理保持每块地皮已选数量和种类不变，尝试统一行列、相邻地皮图案和跨边界同族紧凑性。秋季番茄、土豆库存充足时，单格可种5＋4，四格可各18株，共36株。

开种后锁定整片计划；缺种、缺坑、季节变化或冲突时保留进度并停工，不中途换种或拔除作物。完成后自动寻找下一片，收获并恢复九坑后可开始新一轮。旧v3模板存档只用于原坐标续播；新轮次不再从养分平衡模板中选方案。水分、照料、养分等生长条件仍由游戏和其他农具负责。

## 配置与存档

配置只有语言（跟随游戏/中文/English）、模型相对倍率（75%/标准/125%/150%）和洒水音乐。音乐在Mod设置选择开启、关闭或静音；静音保留植物安抚，取消车辆内单独开关。

保存油量、货仓、车体/配件耐久、水量与配比，读档保持停工。旧仓库挂件迁移到独立挂点；旧打包车无展开位置时保留原归属并重试；旧配比保留现场作物，自动模式重新核验，不复用过期坑位索引；缺种与冲突不强行播种。

工作区腐烂植物分工：收割机采收可采摘的腐烂作物，除草机DIG无法采收且明确腐烂/死亡的农作物残株；保护幼苗、暂时枯萎及被禁用交互的植物。回收腐烂物可直接供施肥机按原版肥效使用。开垦/播种跳过植物，水肥不复活腐烂株；不开工时仍可等待原版返生，采收后原株移除。此修改已收录0.5.8。

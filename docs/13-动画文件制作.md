# Windows 动画编译交付

本轮交付：[`AgeOfMachines-Windows-Animation-Kit.zip`](../AgeOfMachines-Windows-Animation-Kit.zip)，约 4.5 MiB。
详细步骤见包内 `README-zh-CN.txt`，项目中的副本为 [`tools/windows-animation/README-zh-CN.txt`](../tools/windows-animation/README-zh-CN.txt)。

## 你需要做的四步

1. 把完整 ZIP 解压到英文短路径，例如 `C:\AOM\`。
2. 在 Steam 的库中勾选「工具」，安装 `Don't Starve Mod Tools`。
3. 双击包内 `Build-Animations.cmd`；找不到工具时，把安装目录中的 `scml.exe` 拖进黑色窗口并按 Enter。
4. 成功生成 `Animation-Results.zip` 后，把这个结果包发回来。

不用重新出图，不用拆分素材目录，不需要另装 Python。请使用 Steam 安装的完整工具目录，不要只拷贝一个 `scml.exe`。

## 包内内容

- 当前 `AgeOfMachines` Mod，含图标、声音和《兰花草》真实音频包。
- `AgeOfMachines/exported/` 下三个 SCML 工程及全部 18 张引用图片。
- `Build-Animations.cmd`：顺序调用编译器、保留日志、调用结果检查。
- `Collect-Results.cmd`：检查三个产物，收集最终动画、独立 TEX、日志和源文件清单。
- `Source-Manifest.json`：工程、动画名、符号名、图片引用及 SHA-256。
- `Attachment-Preview.png`：保留车头收割台的装配参考图。

没有把现有的三个占位动画 ZIP 放进交付包的 `anim/`，避免误认成编译完成的资源。
实际运行项目中的旧 ZIP 是有效 ZIP 容器，但内部 `.build` / `.anim` 条目为 11 字节的占位文本；它们不是可用的引擎动画。

## 编译命令

`scml.exe` 接收两个参数：源 SCML 和目标 Mod 根目录；最终动画写入目标的 `anim/`。

```bat
"工具目录\mod_tools\scml.exe" "C:\AOM\AgeOfMachines\exported\aom_tractor_chassis\aom_tractor_chassis.scml" "C:\AOM\AgeOfMachines"
```

脚本按同样方式编译三个工程。参数依据为 [Klei 工具源码说明](https://github.com/kleientertainment/ds_mod_tools#usage) 和其 `src/app/scml/main.cpp`。
旧说明中「只把 SCML 拖到 exe」或「最终 ZIP 一定在 SCML 同目录」不适用于这个完整流程。编译器可能在源目录生成中间包，最终包应取自目标 `anim/`。

## 收集与失败处理

收集脚本确认三个 ZIP 内有真实的 `build.bin`、`anim.bin`，检查 `BILD`、`ANIM` 文件头和内置贴图的 `KTEX` 文件头。只有通过检查才报告成功。

成功发回 `Animation-Results.zip`。失败发回 `logs` 文件夹；不要以某个 ZIP 已存在作为成功标准。
批处理使用 Windows 自带 PowerShell，未修改执行策略，不需要关闭安全保护。组织策略拦截时保留提示并发回。

## 当前验证与边界

已经逐个检查三个 SCML 的实体名、动画名、符号名、所有 PNG 引用路径和尺寸；打包后逐文件比对内容并检查 ZIP 完整性。Windows 批处理脚本尚未在真实 Windows 环境执行。

这次是现有世界物体与挂件素材的编译交付。人物坐姿、骑乘中的车体显示和完整方向动画仍需后续接入与实机验证，不能仅凭生成三个 ZIP 视为驾驶画面完成。

## 重新生成交付包

```bash
python3 tools/package_windows_animation.py
```

脚本仅重建项目的 `outputs/windows-animation-kit` 交付暂存目录和交付 ZIP，不改动游戏安装目录或运行 Mod。

# 资源与开发工具链

当前源码版本为 0.5.28。玩家可直接安装已编译的 `Tractor.zip`。运行行为见[核心方案](01-Mod核心逻辑玩法设计与技术方案.md)，测试包和历史安装记录见[验证说明](03-版本测试报告与Bug修复.md)。

## 目录与资源

| 目录 / 文件 | 用途 |
|---|---|
| mod/Tractor | 当前运行目录，`modinfo.lua` 为 0.5.28。内部 `aom` 名称兼容旧档 |
| assets/directional-v2 | 五视图、方向素材、预览及构建记录 |
| assets/images、assets/ui | 图标与界面源素材；PNG不能复制到运行images目录 |
| assets/audio、assets/audio/fmod | 音频源文件、FMOD工程及构建记录 |
| tools、tools/tests | 离线构建/发布脚本、真实Lua模块及原版组件回归 |
| tools/api-ref | 测试使用的原版源码摘录及说明，不是运行Mod组件 |
| outputs | 忽略提交的自检、预览与临时输出；报告证据另存docs/evidence |
| Tractor.zip | 由打包脚本生成，包含 `Tractor/` 和 `INSTALL-MANIFEST.json` |

车体使用 `aom_tractor_chassis.zip`，六种挂件使用 `aom_attachment_shared.zip` 及符号包。四档 `aom_tractor_driver*.zip` 仅保存各自的 `anim.bin`，共享 `aom_tractor_cabin.zip` 的 build 和贴图。角色保留原版 build 和皮肤，驾驶动画做逆向比例补偿。田边蓄水桶使用独立世界动画 `aom_rain_barrel.zip` 和同名制作图集，源素材及生成记录放在 `assets/images/source-art`。

驾驶方向使用原版 `player_idles.zip/idle_loop/5/frame0` 作为侧脸姿势，其他骑乘动作读取归档的 `native-riding-source.anim.bin.gz`。角色贴图由游戏提供。行驶、待机及对话统一坐姿并保留车身悬挂。`mount_geometry.occluded` 控制五种后挂件和水肥流的正面遮挡。重建结果及 SHA 记录在对应的 `Build-Report.json`，`game_validation` 仍为 `false`。

结果FX由服务器在实际作业成功后触发。六个挂件以驾驶员所在格的后方一格为目标。翻土、落种、草屑和收割粒子显示在作业位置或实际处理的目标上，水肥效果也固定在作业地皮。移动作业的排气从驾驶室前方、驾驶员右手边的烟筒口冒出，正面看在画面左侧，背面看在画面右侧。车轮旋转线条仅在侧面和斜向显示，正面与背面保留车身起伏动画。

音频运行文件在mod/Tractor/sound：发动机idle/drive/work使用aom_tractor_sfx.fev/fsb，《兰花草》使用aom_irrigator_music.fev/fsb。拖拉机驾驶时，服务端和预测客户端屏蔽原版骑乘脚步声。静止、空驶和移动作业分别切换到idle、drive和work，同一时刻只播其中一种。源WAV/MP3不能改后缀伪装成运行包。

## 环境与开发命令

Python依赖见[requirements-dev.txt](../requirements-dev.txt)：以requirements-dev.txt为准的Lupa、Pillow和SciPy。图形构建另需ImageMagick与ktech（通常位于~/.local/bin/ktech）；音频重建需FMOD Designer。需要读取原版资源时指定相应含data目录的DST路径，或使用脚本支持的平台自动识别。

仅修改Lua可直接测试和打包；无需重建动画。

```sh
python3 -m pip install -r requirements-dev.txt
python3 -m unittest discover -s tools/tests -v
python3 tools/selfcheck.py --release
python3 tools/package_mod.py
python3 tools/package_mod.py --verify-only
```

自检和package_mod执行适用于整套发布；定向验证可用unittest的-p指定文件。release模式缺依赖、失败、警告、跳过均阻断，不能用只检查语法代替行为回归。

## 按需资源重建

| 变更 | 当前工具与注意点 |
|---|---|
| 图标 / 封面 | `python3 tools/build_tex.py`；用ktech生成KTEX/XML，源PNG留在assets |
| 车体 / 五视图 / 驾驶比例 | `python3 tools/build_directional_art.py`；需要既有驾驶时间线来源及图形工具，脚本也调用配件动画构建 |
| 六类工作动画 | `python3 tools/build_attachment_animations.py`，预览用`python3 tools/preview_attachment_animations.py` |
| 水滴 / 吸水管 | `python3 tools/build_refill_assets.py`编译assets/ui中的SVG为独立水滴KTEX/XML和软管动画；不打包、不安装 |
| 田边蓄水桶 | `python3 tools/build_rain_barrel.py` 从透明底原稿编译场景动画和园艺栏图标 |
| 挂件连接点 / 烟筒口 | 修改assets/directional-v2/mount-layout.json，再执行`python3 tools/update_mount_geometry.py`；仅更新编译动画与hash，保留原贴图。`python3 tools/preview_mount_geometry.py`生成六件×五视图SVG检查图；此命令不打发布包或安装游戏 |
| 配比模板 | `python3 tools/generate_giant_layouts.py`；旧布局用于兼容；现行静态目录另用 `python3 tools/build_seed_catalog.py`，并验证真实坑距、逐格养分和同族 |
| 完整旧驾驶包共享化 | `python3 tools/optimize_driver_assets.py`；先核对全部输入build/贴图一致，保留anim字节；没有资源变动不必重复运行 |
| 编译后的洒水音乐接入 | `python3 tools/install_irrigator_music.py /path/to/fmod-export`；验证真实FEV/FSB配对、事件和结构后接入 |
| 发动机音效重建 | `python3 tools/build_tractor_audio.py --designer /path/to/designer`；在需要Wine的环境另传--wine，参数见脚本--help |

重建会改运行资源和hash报告，应先保证相关源文件可用，在项目中生成，再运行全部发布检查。预览GIF或结构回读是编译产物检查，不是DST截图或实机通过。

## 打包、安装与历史工具

package_mod扫描运行目录，排除隐藏文件、缓存、日志和PNG；逐文件计算SHA-256及长度，临时ZIP校验后才替换Tractor.zip。仅有文档变化不要求重生成相同运行包；正式发布前修改Lua或资源必须重新检查和打包；快速测试阶段先定向验证，需要实测时单独同步到本地游戏，累计后统一发布。

安装解压到游戏mods，使路径为mods/Tractor/modinfo.lua；不要多嵌套一层Tractor目录。更新后完全退出并重启，客户端、服务器同版。本项目打包命令不复制到游戏目录；Windows安装脚本会执行安装，具体调用前应核对其参数和目标目录。

tools/windows-animation、tools/windows-driver及对应打包/导入脚本保留早期交付流程；它们产生的旧三视图或完整驾驶包不能直接覆盖现行五视图、四档共享资源。历史资料见[整理前工具说明](history/2026-11-12-文档重整前/13-动画文件制作.md)与[驾驶接入记录](history/2026-11-12-文档重整前/29-驾驶室坐姿接入.md)。当前发布以运行目录、现行构建脚本和严格自检为准；旧工具只作兼容入口，勿覆盖现行生成物。

[早期驾驶源素材](../assets/driver/README.md)和[测试参考输入](../tools/api-ref/README.md)各有用途说明。图标、残骸和蓄水桶原稿保留在 `assets/images/source-art`。旧驱动 ZIP 提取了必要的人物时间线，保存在 `assets/driver/build/windows-2026-11-11/native-riding-source.anim.bin.gz`。旧 SCML 预览和 Windows 动画交付命令保留迁移说明。

## 工作声与音乐校准

试听C源文件保存在assets/audio/sources/sfxmint-tractor-02.mp3及同名JSON（来源、CC0授权、校验值）；原版参照仅记录样本名称和测量值，不分发原版声音。tools/prepare_tractor_audio.py使用FFmpeg制作单声道无静音接缝循环，并对工作声与保留的音乐原始循环做可重复响度校准；测量记录为assets/audio/loudness-calibration.json。build_tractor_audio.py会先运行该步骤，仅重新合成idle/drive，禁止把work覆盖回旧合成音。音乐另运行build_irrigator_music.py，两个声音包均由正式FMOD Designer编译。FSB5样本偏移、PCM帧数及SHA与源WAV由test_audio_policy.py校验。

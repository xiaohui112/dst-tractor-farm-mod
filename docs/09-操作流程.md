# 操作流程（与代码严格一致）

> 本文件描述**当前代码实际实现**的操作，任何动作分支都能在代码里找到对应。
> 最后核对：本轮修改后。

## 一、完整流程

### 1. 制造与放置
炼金引擎制作「拖拉机（打包）」、科学机器制作六种挂件 → 右键地面放下 → 变成拖拉机本体。

### 2. 手动连接挂件（必须手动）
- 打开拖拉机容器，把挂件放到**第1格**；第2～9格为种子、肥料物料格
- 挂件进入车上第 1 格槽位，车身显示对应挂件
- 没装挂件时车不能作业

### 3. 填充消耗品
| 挂件 | 要填什么 | 怎么填 |
|---|---|---|
| 播种机 | 种子 | 手持种子**右键拖拉机** |
| 施肥挂件 | 肥料 | 手持肥料**右键拖拉机** |
| 洒水机 | 水（新造为空，默认容量40次水壶用量） | 手持装满的水壶或冰块**右键拖拉机** |
| 开垦机 / 打草 / 收割台 | 不需要 | — |
| 全部 | 燃料 | 手持木炭等燃料**右键拖拉机** |

### 4. 上下车（沿用原版骑牛）
**右键拖拉机 → 原版「骑乘」动作上车**，提示文字使用游戏当前语言。驾驶座无需牛鞍或驯化。

**骑乘中右键自己 → 原版「下坐骑」动作下车**。若车上容器仍打开，原版优先提供关闭容器动作，关闭后再次右键自己下车。

上下车分别由原版 `ACTIONS.MOUNT` / `ACTIONS.DISMOUNT` 执行，保留原版动画、客户端预测和动作检查。不再提供 `Shift+F` / `Ctrl+F` 自定义上下车快捷键。

### 5. 作业（F 开关）
- 每次上车**默认关闭作业**，按 **F** 开启，再按 F 关闭。
- 点击下车时立即关闭作业；下次上车仍需按 F 开启。
- 驾驶时 F 不再触发原版攻击；步行时仍保留原版 F 行为。聊天、菜单、暂停时不会切换作业。
- 安装播种机后，左上角面板保留「切换播种策略」按钮；切换策略会停止作业，确认后按 F 重新开启。
- 换挂件、没油、缺料、配比条件不满足时停止作业，按提示处理后按 F 继续。

## 二、驶过地块完成一趟

车辆每0.1秒采样位置，但**不按时间重复作业**。开启后处理起始格一次，此后只处理新驶入的地块；两次采样之间跨过多格时补齐经过的地块。停车不反复扣料，离开再驶入同一格算新一趟。传送等大跨度位置变化不会沿线作业。

| 工序 | 驶过一格完成什么 |
|---|---|
| 开垦 | 铺农田后按原版规则生成杂物，自动铲除并保留原版概率掉落；确认清完后普通模式整理9坑，配比模式按计划整理 |
| 普通播种 | 一次种完本格空坑，每坑消耗一颗种子，无需停车等逐颗播种 |
| 配比播种 | 一次完成本格全部计划坑位，保留布局空位；全部计划地块仍须先准备好 |
| 浇水 | 读取实时水分，按原版每剂25按需浇满100；干地最多4剂，已满不消耗 |
| 施肥 | 使用仓内一份肥料，沿用其原版效果；一趟不等于补满所有养分 |
| 打草 | 铲完本格杂草和园艺残渣，不越界清理邻格 |
| 收割 | 收完本格成熟作物，不越界收邻格，也不自动砸开巨大化作物 |

种子或燃料不足时，已完成的坑位保留，停止继续播种；补充后按 F 处理剩余空坑。失败种子退回，不凭空计数。燃料、底盘耐久仍按实际成功的原版动作结算：例如一格种9颗种子扣9次，停车采样不扣。洒水按单格结算：实际增加水分时，无论用了几剂，只扣1燃料和1底盘耐久；缺水保留进度并停机，补水后按F续浇。

作业开启时按挂件限速：犁地约54%、打草与收割约71%、播种约79%、洒水约93%、施肥100%，百分比相对空驶速度。关闭作业恢复空驶速度。现实参考与游戏尺度见 [11-行驶作业与速度依据.md](11-行驶作业与速度依据.md)。

开垦机实际处理过当前格，且车辆继续在该格移动时，烟筒位置持续产生小黑烟；停车、关闭作业、下车、换挂件或驶入不需耕作的地块后停止产生。世界物体与挂件动画已编译接入；烟筒锚点使用车头上方位置，仍需结合骑乘显示在实机微调。

开垦机耐久为60次，耗尽保留物品并停工；下车手持燧石右键拖拉机，每份恢复10次，满耐久不消耗。发生实际开垦改动时扣1燃料、1底盘耐久和1挂件耐久；部分完成会结算本次实际作业并暂停，未发生改动不扣。已有农田与重试不重复生成杂物。已有作物或建筑会被保护，杂物未清完不重排旧坑。旧 `aom_plow` 物品仍可读档和使用。详见[开垦机实现与验证](11-犁头实现方案.md)。

## 三、驾驶状态面板

骑上车后，屏幕左上角显示：

```
==== 农机时代 ====
挂件：拖拉机开垦机   燃料 400/800   车速 100%
作业中（F 关闭） / 作业关闭（F 开启）
车速：当前作业速度百分比
［切换播种策略］（仅播种机）
```

停机原因会直接显示（没油、没挂件）。

洒水机另显示「水箱 余量/容量 次水壶用量」。普通或高级水壶每1次余量转入水箱1次；冰块每次拆一份补1次；满箱不扣来源物品。旧存档余水按40次容量限制，旧版省略余量的满罐恢复为40次。

音乐已包含真实FMOD音频包并默认开启：洒水作业开启且有水时循环播放《兰花草》，停机、缺水、下车或离开范围后停止，可在Mod配置关闭。音乐异常不会影响洒水。音频构建和完整验证说明见 [洒水机实现与验证](12-洒水挂件实现方案.md)。

## 四、代码对应

| 操作 | 动作 | 实现 |
|---|---|---|
| 上车 | 原版 `MOUNT` | 原版 `rideable` 场景动作 → `ACTIONS.MOUNT.fn` → `Rider:Mount` |
| 下车 | 原版 `DISMOUNT` | 原版 `rider` 场景动作 → `Rider:Dismount` → 原版角色状态机完成 `ActualDismount` |
| 作业开关 | F → RPC `AOM_TOGGLE_WORK` | 校验当前骑手后调用 `aom_drive.lua: ToggleWorking` |
| 播种策略 | 面板 RPC `AOM_SEED_MODE` | 校验当前骑手后调用 `CycleSeedStrategy` |
| 挂载挂件 | 容器第 1 格 | `itemtestfn` 只收 `aom_attachment` |
| 装料 | `AOM_LOAD` | 手持种子/肥料/水壶右键 |
| 加油 / 修理 | `AOM_REFUEL` / `AOM_REPAIR` | 燧石右键修已安装开垦机，齿轮修底盘 |

**状态图**：上下车直接使用原版 `SGwilson / SGwilson_client`。`wilsonbeefalo` 是角色动画 bank，不是单独的骑乘状态图。底盘的 `SGaom_tractor` 提供原版下车流程需要的 `idle` 状态。

**原版组件接入**：底盘保持可点击，`rideable.canride` 随燃料更新；座位占用、死亡等由原版上车动作检查。`rideable.shouldsave=true`，让原版角色存档包含正在骑乘的车辆。

**回归验证**：`tools/tests/test_native_riding.py` 执行原版 `rider / rideable` 组件和上下坐骑动作，检查提示、完整上下车、下车停工、占位、缺油、容器优先关闭、F 输入、速度同步和播种策略按钮等。引擎与控件使用桩，不能替代实机验收。

## 六、暂时不做的事

- **自动驾驶已移除**：原实现每 0.1 秒直接改坐标、只查地形不查建筑，风险高。等手动流程跑顺再考虑。
- **未实现的配置项已从菜单移除**：驾驶速度、普通地皮可翻、收获进背包、巨大化作物保留、调试日志。现在菜单里只有「语言」。


## 配比播种修复版（2026-11-11）

巨大化模式不再按连续株数跨格拼配比。当前使用方法与限制以 [10-巨大化配比.md](10-巨大化配比.md) 为准：装齐种子 → 切换配比 → 换犁头准备全部相邻地块 → 换播种机按固定坑位种植。第1格为挂件，第2～9格为物料；HUD增加布局进度与暂停原因。只有本格作业实际成功才扣作业燃料。

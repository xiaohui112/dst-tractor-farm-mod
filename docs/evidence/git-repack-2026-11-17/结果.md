2026-11-17。按用户授权，仅改变本地对象存储表示，不改写历史，不过期reflog，不回收不可达对象；网络获取已禁用。

命令明确使用 `git repack -a -d --keep-unreachable`，配合50对象差量窗口、深度50、2线程、每线程256MiB窗口内存上限；没有调用gc/prune/reflog expire。`-d`移除的是冗余存储副本，所有唯一对象均保留。部分克隆的promisor对象仍单独打包，按需获取机制和配置保留。

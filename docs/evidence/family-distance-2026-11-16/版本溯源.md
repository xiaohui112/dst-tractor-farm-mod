# 同族距离精度问题的版本溯源

2026-11-16，仅核对历史与离线复现，未修改 Mod。

## 已确认

| 历史节点 | 证据 | 可得结论 |

`git log --all --follow` 用于追踪早期 AgeOfMachines → Tractor 目录迁移，避免把0.5.1的迁移误认作模块首次创建。

## 旧代码复现

直接用 `git show 2384b52:mod/Tractor/scripts/aom_seed_layout.lua` 读取0.5.13模块，在 Lua 5.1 中加载，仅调用其原始 `Geometry`。使用与本轮对照相同的 `autumn/square-3/all-40/GIANT` 双精度坑位输入，与整数索引数学基准比较：

```json
{
  "commit": "2384b52",
  "version": "0.5.13",
  "missing_directed_edges": 36,
  "missing_undirected_pairs": 18
}
```

该实验只核对几何邻接，没有运行旧版完整求解和计时，因此不能宣称0.5.13也必定同样超时。不同版本的构造、搜索路径和库存场景可能改变症状。

## 结论边界

这是早期留下的数值模型一致性隐患；目前已证明这次具体的离线邻接误判至少在0.5.13存在，不是接入CP-SAT或近期优化才产生。CP-SAT原型始终独立运行，没有改写Mod。

0.5.9至0.5.12未逐版独立提交，安装报告列出的旧备份目录目前也已不在原位置；不据文档推定其中某一版是精确引入点。

原版引擎读回的坐标已是float32→double，本次离线输入保留原始double。历史代码证据不能直接推出旧版游戏现场也具有同一个 `16.000000000000007`，更不能推出所有实机超时均由它引起。后续需要用对齐引擎的输入重新测速，并与现场日志对应。

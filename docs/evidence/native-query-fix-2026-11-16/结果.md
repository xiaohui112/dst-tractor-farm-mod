# 原版范围查询修复与复测

2026-11-16，基于工作区 0.5.20 修改 Mod 源码，保留现有 Lua 求解器。未打包、安装到游戏或推送。

后续安装记录：用户授权后，版本升为 0.5.21，完成发布检查（692 个行为回归、18 项检查，无失败或警告），生成 Tractor.zip 并安装至本机游戏的 mods/Tractor。98 个源文件与压缩包及安装目录逐字节一致，旧目录和旧包已备份。未重启游戏、未推送；实机验收由用户进行。见[安装校验](../0.5.21-game-install-validation.json)。下文保持安装前离线复测口径。

## 修改内容

- 实际坑位的同族范围和坑距冲突统一采用原版 `TheSim:FindEntities` 查询结果；不再用 Lua double 距离作二次过滤，不添加 epsilon，不在 Mod 内模拟 float32。
- 查询结果按本次采集的坑位缓存，精确搜索、可行解搜索、排列合法性及续播校验共用。排列评分保留原有距离计算。
- 保存实际 x/y/z；加载存档先检查结构，现场实体恢复后、播种前重验。坑位缺失不能返回最优证明；原版排除的 killjoy 作物不能充当同族支持。
- 库存、季节、密度、逐格养分净零和 4+4 中心空位等规则保持不变。离线测试与网页验证器模拟原版引擎接口，直接加载 Mod 代码。

## 解释与限制

此次超时的主要诱因是错误删除了原版接受的边界邻接，导致原本可快速达到上界的布局被拒绝，转入昂贵搜索。恢复正确邻接后，这批超时场景均消失。目前保留 Lua 求解器有依据，无需为此问题切换 CP-SAT。

本次是修改后的 Lua 复测，CP-SAT 数量参照之前冻结实验；没有在本轮重新跑 CP-SAT 性能竞争。前后可行域发生纠正，不能把耗时改善称为同一数学问题上的纯求解器加速。

测试使用共享开发机；部分时间与全量自检并行，离线 FindEntities 为 Python 模拟实现。数据只代表这批离线场景，不保证所有库存/地形均无超时，也不代表实际游戏帧率、多人同步或作物生长已验收。

# 0.5.18：两种巨大化策略及验证记录

日期：2026-11-16。以下为本机原始Lua5.1／网页离线验证，不是DST客户端FPS、实际生长或多人联机验收。

## 实现范围

策略顺序为“顺序 → 巨大化·模版 → 巨大化·最优”。旧存档GIANT仍代表最优，新增GIANT_TEMPLATE。切换停工、清除旧计划和预览；缓存键与存档区分两种巨大化策略。

模版模式直接在Mod新增`aom_seed_templates.lua`：标准3×3坑位、固定形状、旋转镜像、库存选配与有限拆换回填。包含单格4＋4中心空、双格4＋8／4＋4＋4，以及双格6＋12／6＋6＋6种满18坑；四格支持8＋8＋16和8＋8＋8＋8的32株对称图案，四角留空。按原版净养分向量筛选可替换作物，18种参考图作物组合逐坑验证；不调用逐坑精确搜索，不打散模版内部位置。模版可以少于全田最大数量，不将它冒充最优策略。

最优模式保留应季、库存、真实坑距与同族、逐地皮三类养分净变化为零等硬条件；先完整证明最大合法播种量，再按同族紧凑、排列整齐整理。新优化为：模版合法下界、保留区域构造的部分合法结果、复用未改变候选域的界及同族传播汇总。辅助方法只提供下界，失败不会排除解，不采用货仓顺序优先，也没有超时就返回少播方案。两种策略都不读取当前土壤养分。

网页由同一Lua入口按策略分派；宽高输入有效时自动重建矩形，再手动编辑地皮。库存使用只显示输入库存大于0的作物，未使用但有库存的保留。数量点击全选直接替换，允许暂时空值；再次点同株、画布空白或Esc取消坑位检查。旧JSON缺少策略字段时按GIANT处理。

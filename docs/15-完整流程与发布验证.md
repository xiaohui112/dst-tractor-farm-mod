# 0.2.0 完整流程与发布验证

本版补齐独立加载、原版放置链路、加油、底盘与播种机耐久、损毁回收、中英文界面及安装包一致性。版本0.2.1，自动回归216项；未进行真实DST客户端或联机验收。

## 玩家规则

| 项目 | 行为 |
|---|---|
| 放置 | 预览名与打包物品对应，按地块中心校验；障碍拒绝，物品保留 |
| 加油 | 木炭等可燃燃料每次消耗一份，油量封顶800，满箱不消耗 |
| 底盘 | 1000次实际作业，归零停工，齿轮每份恢复100 |
| 播种机 | 100颗成功种子，失败不扣；燧石每份恢复10 |
| 开垦/除草/收割 | 分别60/50/40次实际整格作业，燧石每份恢复10 |
| 面板 | 显示底盘/挂件耐久、种子/水/肥料余量和暂停原因；中英双语 |
| 打包 | 原槽位、物料堆叠/用量、油量、底盘耐久、血量和配比绝对坐标进度保留 |
| 损毁 | 停工下车，掉落全部挂件和物料，禁止再次打包成新车；旧死亡存档也会回收物料 |

播种按颗结算，其他整格工序按实际变化结算；底盘最后一次耐久不会透支到下一次动作或后续地块。

## 完整流程测试

`tools/tests/lifecycle_engine.lua` 加载真实Mod装配及原版 `MakePlacer`、`Deployable`、`Container`、`InventoryItem`、`Stackable`、`Fuel`、`FarmPlantable`、`Workable`、`FiniteUses`、`Rider`、`Rideable` 和实体存读档方法。没有虚构的 `GLOBAL.containers`，没有用空函数代替放置校验。

`test_lifecycle_flow.py` 的13项流程包括：

1. 独立模块加载、真实预览对象、自定义放置模式。
2. 障碍拒绝、有效地块中心放置、失败保留物品。
3. 可燃燃料右键动作、满箱与部分余量整份消耗、拒绝异类燃料。
4. 空油禁止上车，经实际加油动作恢复原版骑乘。
5. 装种子、上车、开工、播种机耗尽、下车燧石维修、本格边角续种。
6. 底盘耗尽停工、拒绝免费作业、齿轮修复续作。
7. 满9格打包、原版存档重建、异地放置，核对全部物料及状态。
8. 稀疏槽位和出厂空水箱的打包恢复。
9. 损毁下车、全部物料只回收一次、不生成新车。
10. 英文Mod环境配置、动作/状态/面板、仅用网络字段显示耐久。
11. 客户端分支不创建服务端组件。
12. 专用服务器分支不依赖客户端输入对象。
13. 旧死亡存档在组件全部恢复后回收物料。

地图、实体、网络、物理、声音及血量底层仍为测试桩；健康状态变化用于触发生命周期，未模拟游戏战斗。原版农业回调、109种配比、洒水、施肥、除草、巨大作物及驾驶动画另有现有回归覆盖。

## 安装包生成与核对

```bash
python3 -m pip install -r requirements-dev.txt
python3 tools/package_mod.py
python3 tools/package_mod.py --verify-only
```

打包器先执行全部自检，通过后再创建临时ZIP；包内文件与源码、清单全部核对一致后，才替换 `AgeOfMachines.zip`。清单记录每个运行文件的SHA-256与大小，检测缺失、新增、重复、陈旧或被修改的文件，并校验ZIP CRC。

两个Windows重建工具包分别运行 `tools/package_windows_animation.py` 和 `tools/package_windows_driver.py`。动画工具包有意去掉待重编的世界动画；驾驶工具包有意去掉驾驶动画并写入未启用清单，成功构建后才启用。它们不应被当成直接可安装的成品包。

## 清理边界

删除已被正式动画替代的占位包生成器、已解包并被新版工具包替代的旧美术/源码归档，以及本地缓存和临时日志。保留运行资源、SCML/PNG/SVG源工程、音频工程、原版测试依据、Windows返回结果包及其来源校验记录，保证现有构建仍可追溯。

## 1. 里程碑

| 阶段 | 目标 | 交付物 | 验收标准 |
|---|---|---|---|
| **M0 骨架**（0.5d） | 工程可跑 | `modinfo.lua`、`modmain.lua`、空 Prefab、可放进 `mods/` 并在服务器加载 | 游戏内 `c_give("tractor_chain")` 不报错 |
| **M1 底盘**（1d） | 底盘可放置、可加油、可骑乘 | 底盘 + 挂件槽 + 油量 + `rideable`/`locomotor` | 右键骑上车，车速为角色 75%，再次右键下车 |
| **M2 开垦机**（1.5d） | 第一种挂件跑通 | 开垦机（园艺耕地机 + 园艺锄）+ 耐久 | 开车走一条直线，地上连续出现 Farm Soil Turf 与土坑；与手动用原版工具结果一致 |
| **M3 播种机**（1d） | 播种 | 播种机 + 种袋（走原版 PLANTSEED） | 犁完的垄能自动播种；随机种子/作物种子的生长结果与原版一致 |
| **M4 洒水机**（1d） | 浇水 | 洒水机 + 水箱（对应原版洒水壶 +25） | 车前土坑补到 100 即停，不无限水；能用原版水壶/池塘补水 |
| **M5 收割机**（1.5d） | 收割及锤开巨大作物 | 原版Pickable + HAMMER | 按原版规则采摘及拆分，整格实际结算，失败保留进度并暂停 |
| **M6 施肥 + 除草机**（2d） | 补齐原版剩余两件工具 | 施肥机（原版肥料 USEITEM）+ 除草机（铲子 DIG） | 施肥加成与原版肥料完全一致；只铲杂草与残渣，不误伤作物与移植植物 |
| **M7 打磨**（2d） | 可发布 | 中英文本地化、模组设置、平衡数值、音效、图标、预览图、创意工坊页面 | 两人联机稳定跑 1 小时不报错 |
| **V2**（可选） | 扩展 | 巨大化作物自动锤开（默认关）、电动化（女工电力）、多底盘并行 | — |

**总计：V1 约 11 个工作日工作量**（熟悉 DST Mod 开发的 1 人，按每天 6h 有效工时）。

## 2. 分工建议（2 人并行）

| 角色 | 负责 | 并行起点 |
|---|---|---|
| 程序 A | 底盘、挂件槽、RPC、驾驶态、同步 | M1 |
| 程序 B | 开垦机 / 播种机 / 收割机的作业判定 | M2（先用 `c_spawn` 假数据跑） |
| 美术 | 底盘 + 6 个挂件（每个 prefab 一套 anim + 图标） | 与 M1 同时 |
| 文案/测试 | modinfo、创意工坊介绍、平衡表 | M7 前 3 天 |

**美术资源是最大瓶颈**：DST 的动画是 `.zip` + `.tex`，第一次做建议直接**复用原版素材 + 换色/缩放**（`anim/` 里找 `farm_plow`、`sprinkler`、`boat`、`wagon`），先让"看着像"，M7 之前不追求原创精模。

## 3. 开发规范

- 每个 prefab 一个文件，文件名与 prefab 同名，统一放在 `scripts/prefabs/`。
- 所有给玩家看的字符串走 `STRINGS`，中文集中在 `scripts/strings.lua`，`modmain` 里做语言切换（`GetModConfigData("language")`）。
- 兼容性：不修改原版组件（不 `AddComponentPostInit` 到 `farmplant` 除非必要），只加 `tags`。
- 与已有 Mod 共存：如果检测到 `tractor`(3748361628)、`farm_automation` 等冲突 Mod，在 `modmain` 里 `AddGamePostInit` 打一条警告到聊天窗。
- 每个阶段都要有 `c_regenerateworld` 后的冷启动测试。

## 4. 风险表

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 巨大化作物判定在版本更新后失效 | 中 | 高 | 只调原版 `harvest`，不重写；加"兼容模式"开关 |
| 骑乘与驯牛互相冲突 | 中 | 中 | 已在骑牛时拒绝上车；车被移除时强制 `ActualDismount` |
| 与 `tractor`(3748361628) 同类 Mod 用户分流 | 高 | 中 | **做出"挂件"差异 + 更低的制作门槛 + 移动作业**；创意工坊页明确写"与 XX 的区别" |
| 掉落物过多卡顿 | 中 | 中 | 收盘直接进背包（默认开），单一 tick 上限 9 |
| 施肥机写死养分数值 | 中 | 高 | 一律走原版肥料 USEITEM 入口，不自造 +8/+16/+24；0 号任务核对加成表 |

## 5. 发布准备

- `modinfo.lua`：Mod 中文名为 **拖拉机**，英文名为 **Tractor**。
- 必需图片：`modicon.tex`（512×512）、创意工坊预览图 3~5 张（底盘特写 / 挂件合集 / 开车犁地截图 / 洒水机浇水截图 / 主界面）。
- 创意工坊描述要写清：① 与同类 Mod 的区别；② 模组设置项清单；③ 已知兼容性问题。
- 首发版本号 `1.0.0`，同时建一个 `dev` 分支，避免频繁上传把首发评价拉低。

# 开垦机实现与验证（兼容旧开垦机）

> 当前版本：2026-11-11。文件名保留历史名称，正文描述当前 `aom_landclearer` 实现。
> 上下车沿用原版骑牛，F 开关作业，每次上车默认关闭，下车立即停止。驶入地块一次完成整格工序，停车不重复作业。

## 职责与顺序

开垦机负责播种前整理：铺农田、生成原版规则的农场杂物、自动铲除并保留掉落、验证清理完成，然后整理土坑。遇到未收获作物或不可清理的障碍物会暂停，不砍树、不采石、不拆建筑。除草机仍用于生长期除草，不重排坑位。

1. **保护检查**：普通模式保护本格已有作物；配比模式由规划器核对并保留已记录作物。无法通过 DIG 清理的杂物、建筑及其他障碍会阻止作业，旧土坑先保持原状。
2. **铺农田**：只有非农田格调用原版 `Terraformer:Terraform`；不使用额外的 `Map:SetTile` 捷径。既有农田直接进入清理阶段。
3. **生成杂物**：载体设置 `onterraformfn`，因此成功铺地后同步运行生成规则。规则对应原版 `farm_plow.OnTerraform` 的杂物部分：次数读 `TUNING.FARM_PLOW_DRILLING_DEBRIS_MIN/MAX`，范围读 `TILE_SCALE×0.9`，新杂物间距不足1的随机位置跳过。
4. **铲除并掉落**：只处理本格可通过原版 DIG 执行的杂草与 `farm_soil_debris`，调用其 `workable:WorkedBy(driver, remaining_work)`。原版杂物 prefab 自己决定掉落，Mod不手动删除杂物、代造掉落或强制捡入仓库。
5. **确认清理完成**：重新扫描整格；仍有杂物则暂停，不接着删除旧土坑或挖新坑。铲除回调可能改变场地，因此再检查一次保护对象。
6. **整理坑位**：普通模式为3×3九宫格，配比模式为本格尚未播种的计划位置。先清掉不在目标位上的空坑，保留匹配坑位，再通过原版 `CanTillSoilAtPoint / CollapseSoilAtPoint` 补坑。
7. **确认整格完成**：无残留杂物，所有所需空坑都在目标位置，没有多余空坑。不能只因为铺了地或挖出部分坑就判定完成。

原版范围是2～4次随机尝试，因位置过近可能跳过，不能强行保证生成2～4个实体。既有农田、失败重试、重复驶过不会再次生成杂物。原版杂物当前掉落概率为25%，且受原版运气逻辑影响，并非每个杂物必定有掉落。

源码依据：[farm_plow.lua](https://github.com/vietnd69/dst-scripts/blob/main/prefabs/farm_plow.lua)、[farm_soil_debris.lua](https://github.com/vietnd69/dst-scripts/blob/main/prefabs/farm_soil_debris.lua)。复用的是杂物生成与铲除规则，不复用会拆除原版耕地机的 `Finished`，也不等待原版固定部署计时。

## 完成状态与消耗

`AOMFarmWork.Plough` 返回三个值：

| 情况 | changed | reason | ready |
|---|---|---|---|
| 全部整理完成 | true | nil | true |
| 原来就已完成 | false | ALREADY_TILLED | true |
| 修改前发现作物、建筑等障碍 | false | 具体原因 | false |
| 已铺地／铲除／挖部分坑，但没有完成 | true | 具体原因 | false |

预检和完成检查共用坑位匹配与整格范围：半径2.9覆盖地块边角，再按所属地块过滤，避免清理邻格；不再用2.8与2.9两套清理范围，也不只靠“有无可挖的新坑”判断手工错位坑是否需要整理。

发生实际改动时，每次本格开垦结算1燃料、1底盘耐久和1开垦机耐久，包括部分完成后暂停的情况。没有发生改动的失败，以及已经整理好的重复作业不扣消耗。部分完成保留现场，排除问题后按F继续；重试不会重生杂物或重复产出其掉落。

## 配比模式

准备阶段允许开垦机处理可铲除的杂物，不能在 `CheckField` 中把它们提前当成其他作物拒绝。播种阶段继续严格拒绝未清理杂物和非计划作物。

所有地块准备好后才播种；留空位保持空着。收获后的可清理残渣不再阻止启动下一轮，但尚未收获的计划作物仍被保护。

## 挂件耐久、修理与旧存档

- 新配方为 `aom_landclearer`，仍需燧石×10、木板×2、科学机器。
- 开垦机有60次独立耐久，耗尽停止作业，保留物品供修理。
- 下车后手持燧石右键拖拉机修理已安装的开垦机：每份恢复10次，上限60；满耐久不扣材料，每次只消耗一份堆叠材料。
- 齿轮继续修理底盘。洒水机的 `finiteuses` 记录储水，不被当作开垦机磨损或用燧石维修。
- 保留旧 `aom_plow` prefab 入口、旧物品原有耐久存档数据及引用，显示名与图标映射为新开垦机；不增加重复制作配方，不强制替换旧实体。

## 验证与边界

运行：`PYTHONPATH=/tmp/pylua python3 tools/selfcheck.py`。

新增流程测试直接执行原版 `Terraformer`、`Workable`、`FiniteUses` 和 `farm_soil_debris` prefab，不以手工删除杂物代替原版掉落回调。覆盖新地块完整执行顺序、100组随机种子与原版生成回调对照、全部109条配比的新地块开垦及播种、边角与邻格隔离、错位旧坑、作物及建筑保护、清理失败、挖坑未完成、重试不重生杂物、耐久耗尽、维修及旧prefab读档。

地图、实体底层、运气与掉落选择的测试输入仍为可观察桩，不等于在 DST 引擎中完成地图、碰撞、存档和联机验收。世界动画已在后续接入 Windows 编译产物，骑乘显示仍待接入与实机验证。

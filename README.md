# Tractor｜饥荒联机版农场机械

拖拉机提供驾驶、15格货仓和一个独立挂点。六种设备通过原版农业组件执行开垦、播种、洒水、施肥、除草和收割。

## 安装与上手

1. 将[mod/Tractor](mod/Tractor)复制到DST的 `mods/`。路径应为 `mods/Tractor/modinfo.lua`。
2. 启用“Tractor”；更新后完全退出并重启游戏，客户端与服务器保持同版。
3. 在园艺栏用炼金引擎解锁制作。右键有油的拖拉机上车，靠近设备右键挂载，按F开启/关闭持续作业。
4. 先开垦九宫格，再挂播种机并往货仓装种子。播种机图标下方显示当前模式，空手左键按“顺序→巨大化·模版→巨大化·最优”切换，悬停可查看下一档。
5. 巨大化规划完成后显示绿色待播预览，等待2秒自动开始；驾驶经过目标地皮继续播种。缺料或停工处理后按F续作。

下车、换件和切换策略会停工。左键车体/自己或货仓表盘开关货仓，右键车体/自己下车；右键挂件表盘卸载。

播种在一格本轮成功种下第一颗时扣1燃料、1底盘耐久，播完该格时扣1机械耐久。其他设备每格有实际农业改动扣燃料、底盘、机械耐久各1。种子、水、肥料按实际用量另扣。仅拾取或无变化不计农业成本。行驶每8世界距离另耗1燃料。空驶速度为原版人物基础跑速的100%，按F作业为50%（默认6和3世界单位/秒）。

## 巨大化播种规则

新田九宫格坑距为 **1.3125**，旧田保留实际坐标；收获后重新开垦空田才更新坑位。两种巨大化策略都约束应季、库存、原版坑距/密度、逐株同族、每地皮三类养分净变化为零；不读取当前土壤肥力，不保证后续水分、照料等压力达标。

“巨大化·最优”扫描起点四边连通的完整空九宫格，最多64地皮；先证明最大合法数量，再按同族紧凑、排列整齐整理。数量证明没有少播超时降级，复杂输入可能等待较久，可停止作业。“巨大化·模版”按静态审核图案整块选配，不设固定连通地皮上限，不承诺全田数量最优。

规划在服务端分帧执行。房主可在 Mod 设置的“巨大化规划每帧额度”选择2/4/8/12/16/24/32毫秒，默认16毫秒；保存设置并重新载入世界后生效，可按流畅度调整。额度越大通常等待越短，但更容易卡顿。后台预计算固定1毫秒。头顶显示进度，结束时向驾驶者的本地控制台打印一次结果，可按 `~` 回看；服务端同时保留标准输出。已播计划保存实际坐标及完成进度，缺种、季节变化或现场冲突会保留进度停工。详见[巨大化最优详细报告](docs/reports/巨大化最优设计与验证报告.md)。

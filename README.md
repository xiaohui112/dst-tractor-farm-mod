# 拖拉机（Tractor）

《饥荒联机版》拖拉机与农场挂件 Mod。包含开垦、播种、洒水、施肥、除草和收割六类挂件，农业操作沿用原版组件与数值。

**当前为开发版本，世界物体、挂件与驾驶室坐姿动画已完成 Windows 编译并接入，驾驶显示已启用。没有完成 DST 实机与联机验收。** 已完成的行为回归不能代替游戏内验证。

## 名称约定

Mod 中文名为 **拖拉机**，英文名为 **Tractor**。默认跟随游戏语言，也可在 Mod 配置中手动选择中文或英文；旧存档已有语言设置继续生效。

| 配件名称 | 英文名称 |
|---|---|
| 开垦机 | Land Clearer |
| 播种机 | Seeder |
| 洒水机 | Irrigator |
| 施肥机 | Fertilizer Spreader |
| 除草机 | Weeder |
| 收割机 | Harvester |

制作菜单、物品与世界实体名称、驾驶面板标题和当前文档采用上述名称。`AgeOfMachines` 目录及交付包文件名、`aom_*` 内部 ID、动画和存档键保持兼容。

## 当前功能

- 原版骑乘动作上下车，F 切换作业，上车默认关闭、下车自动关闭。
- 驾驶室显示已接入原版骑牛坐姿，保留角色与皮肤，按六个朝向处理人物与窗框前后层次。
- 根据车辆经过的地块触发作业，停车不重复扣料，作业速度随挂件变化。
- 原版自定义放置校验与地块对齐；木炭等可燃燃料右键加油，整份消耗、油量封顶。
- 开垦机铺农田、按原版规则生成杂物、铲除并保留概率掉落、确认清理后整理坑位。
- 播种支持顺序、随机和巨大化配比规划。
- 底盘1000次耐久、播种机100次耐久实际结算；耗尽停工，齿轮修底盘，燧石修四种耐久挂件。驾驶面板显示耐久及种子余量，支持中英文反馈。
- 洒水机出厂空罐、默认容量 40 次水壶用量，支持水壶和冰块补水、旧存档迁移、按实时水分浇满与实际消耗结算。
- 施肥机按需补齐三类养分，支持多次用量、按实际次数装料、缺肥续作和整格结算。
- 除草机仅处理可DIG的杂草和园艺残渣，优先保护作物，清理后复查；50次耐久按实际作业地块扣除，支持燧石维修。
- 收割机一趟采摘本格普通及巨大作物，并按原版HAMMER掉落拆开巨大产物；40次挂件耐久按实际作业地块扣除，耗尽停工，支持燧石维修；保留打蜡装饰、持有物品和邻格对象。
- 《兰花草》真实 FMOD 音频包已包含；客户端音乐独立运行，音效异常不影响洒水。
- 收割机美术源工程保留车头独立挂点。
- 满仓打包、存档重建、异地放置保留物料、油量、耐久、血量和配比进度；损毁时强制下车，回收全部挂件/物料后移除车体。

具体操作和实现范围以[操作流程](docs/09-操作流程.md)、[开垦机](docs/11-开垦机实现方案.md)、[洒水机](docs/12-洒水机实现方案.md)、[施肥机](docs/14-施肥机实现与验证.md)为准。早期方案和 `TASKS.md` 保留设计历史，可能与当前实现存在差异。

## 开发验证

需要 Python 3.9 或更高版本。安装开发依赖后运行：

```bash
python -m pip install -r requirements-dev.txt
python tools/selfcheck.py
```

当前版本 **0.2.0**，基线为 **213项回归通过（含 Lua 5.1 行为、完整流程、安装包一致性与驾驶动画构建测试）**，另检查三个世界动画包及驾驶动画包的 BILD/ANIM/KTEX 结构、动画名及符号。测试执行真实 Lua 模块及原版放置、容器、物品归属、作业和存读档组件，地图、实体、网络和声音底层使用测试桩。验证范围见[完整流程与发布验证](docs/15-完整流程与发布验证.md)。

验证通过后生成安装包，并逐文件核对源码及清单：

```bash
python3 tools/package_mod.py
python3 tools/package_mod.py --verify-only
```

包内 `INSTALL-MANIFEST.json` 记录所有运行文件的SHA-256；校验报告位于 `outputs/install-validation.json`。Windows返回的两个结果归档及构建来源清单保留供追溯；缓存、旧版重复美术包和占位动画生成器已清理。

重新生成 Windows 动画交付包：

```bash
python tools/package_windows_animation.py
```

音乐的构建工程、编译记录和检查工具已入库；FMOD Designer、Wine、Steam Mod Tools 等工具本身不包含在仓库内。后续音频重建参见[洒水机文档](docs/12-洒水机实现方案.md)。

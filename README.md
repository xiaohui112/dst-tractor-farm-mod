# Tractor｜饥荒联机版农场机械

当前代码与本机安装版本 **0.5.23**。拖拉机提供驾驶、15格货仓和一个独立挂点；六种设备通过原版农业组件执行开垦、播种、洒水、施肥、除草和收割。

## 安装与上手

1. 将[Tractor.zip](Tractor.zip)解压到DST的 `mods/`，或复制[mod/Tractor](mod/Tractor)。路径应为 `mods/Tractor/modinfo.lua`。
2. 启用“Tractor”；更新后完全退出并重启游戏，客户端与服务器保持同版。
3. 在园艺栏用炼金引擎解锁制作。右键有油的拖拉机上车，靠近设备右键挂载，按F开启/关闭持续作业。
4. 先开垦九宫格，再挂播种机并往货仓装种子。空手左键挂件表盘按“顺序→巨大化·模版→巨大化·最优”切换。
5. 巨大化规划完成后显示绿色待播预览，等待2秒自动开始；驾驶经过目标地皮继续播种。缺料或停工处理后按F续作。

下车、换件和切换策略会停工。左键车体/自己或货仓表盘开关货仓，右键车体/自己下车；右键挂件表盘卸载。

成功播种一颗扣种子1、燃料1、底盘耐久1，播种机在本格计划/空坑播完时扣机械耐久1；中断续播不重复计费。其他设备每格有实际农业改动扣燃料、底盘、机械耐久各1，水肥按实际剂数另扣。仅拾取或无变化不计农业成本。行驶每4世界距离另耗1燃料，空驶和关F时也生效；速度统一为原版人物初始跑速50%。

驾驶时拿起燃料点燃料表盘补油；拿起齿轮点生命/底盘表盘，每份分别修100；拿起燧石点挂件表盘，每份修10。地面设备可手持燧石右键修理。损坏设备保留可维修；车体死亡落货与挂件并留下可维修残骸。

## 巨大化播种规则

新田九宫格坑距为 **1.3125**，旧田保留实际坐标；收获后重新开垦空田才更新坑位。两种巨大化策略都约束应季、库存、原版坑距/密度、逐株同族、每地皮三类养分净变化为零；不读取当前土壤肥力，不保证后续水分、照料等压力达标。

“巨大化·最优”扫描起点四边连通的完整空九宫格，最多64地皮；先证明最大合法数量，再按同族紧凑、排列整齐整理。数量证明没有少播超时降级，复杂输入可能等待较久，可停止作业。“巨大化·模版”按静态审核图案整块选配，不设固定连通地皮上限，不承诺全田数量最优。

规划在服务端分帧执行；当前仅保留头顶进度和内存计时。已播计划保存实际坐标及完成进度，缺种、季节变化或现场冲突会保留进度停工。详见[巨大化最优详细报告](docs/reports/巨大化最优设计与验证报告.md)。

## 开发与验证

```sh
python3 -m pip install -r requirements-dev.txt
python3 tools/package_mod.py
python3 tools/package_mod.py --verify-only
```

打包前执行严格发布自检，失败、警告或跳过会阻断。打包命令不自动安装到游戏。最新0.5.23记录为698项Lua行为回归、18项发布检查通过；98个文件在源码、ZIP和本机安装中一致。离线/模拟验证不替代真实客户端、联机与生长验收。

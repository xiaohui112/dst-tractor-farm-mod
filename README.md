# Tractor｜饥荒联机版农场机械

当前已打包版本 **0.5.6**。驾驶拖拉机、更换六种独立挂件，完成开垦、播种、洒水、施肥、除草和收割。农业效果及产物沿用原版组件，增加机械消耗、配比规划和自动养护；不加速作物生长，也不强制巨大化。

0.5.6统一收录快速测试阶段的修复：烟筒与挂点对齐、播种耐久/水箱400、货仓堆叠总数、取消挂件下方条、水滴表盘、音乐三态和5秒软管补水。除草机会先清理本格作业目标周围10距离内的刺针旋花，再处理普通杂草，保留破根须脱困。

九格货仓全部存货与物料，挂件使用独立挂点。直接删除挂件会立即停工并释放挂点，可继续换挂。设备制作后直接落地，挂件不能拿进背包，耐久耗尽保留实体，可维修复用。

## 安装与更新

1. 下载仓库根目录[Tractor.zip](Tractor.zip)，解压到DST的`mods/`；也可复制[mod/Tractor](mod/Tractor)。
2. 确保目录为`mods/Tractor/modinfo.lua`，没有多套一层文件夹。
3. 启用Mod列表中的“Tractor”。更新后完全退出并重启游戏，客户端与服务器使用同一版本。

已包含编译好的动画、贴图及FEV/FSB声音，玩家无需安装开发工具。本版457项行为回归及17类严格发布检查通过；实际客户端画面、双人联机与专服仍待验收，详见[版本报告](docs/03-版本测试报告与Bug修复.md)。

## 第一次使用

七种设备均在原版“园艺”栏，首次解锁需要炼金引擎。

1. 制作拖拉机和开垦机，确认放置位置。
2. 右键有油的拖拉机上车，靠近开垦机并右键挂载。
3. 按F开启，驶过空地铺农田并准备九坑；再按F关闭。
4. 右键已挂配件卸载，换播种机，把种子放入货仓，再按F播种。点击最右侧配件表盘可打开播种策略与配比设置，默认不常驻下方条。
5. 后续换洒水、施肥、除草、收割设备。货仓满或缺料时处理原因，再按F继续。

作业开启后松F不会关闭；停车不重复农业作业。换件、下车和切换播种策略会停工。原版移动操作驾驶，左键车身/自己或点击货仓表盘开关仓库，右键车身/自己下车。

开垦、除草、收割自动收入本格散落物及本次作业掉落，不搬驾驶员已有库存；满仓保留地面余量并暂停。货仓表盘数字显示含堆叠的物品总数（9组40颗种子显示360），悬停仍显示占用格数；九格占满时同类物品仍可能叠堆。

## 补给、维修与损毁

- 油量初始400、上限800。下车手持有效可燃燃料右键车身，每份按原版fuelvalue补充，满油不消耗；空驶和停车不按时间耗油。
- 种子和肥料放任意货仓格；装对应设备后，也可下车手持物料右键车身装料。
- 洒水机出厂空罐。驾驶到可取水池塘旁右键“补满水箱”；下车可用装水的普通/高级水壶或冰块补水。
- 挂件零耐久停工并尝试卸载；下车手持燧石右键地面挂件，每份+10，满耐久不消耗。维修不补水或物料。
- 齿轮右键车体或残骸，每份同时恢复100生命和100底盘耐久，各自封顶。

没有安全卸载点时保留设备，驶到空地再卸载。车体生命归零强制下车、落货与配件，留下可保存、可修理的残骸；锤拆返还齿轮2、电子元件1、木板3、燧石4，不生成便携打包车。

## 配比种植

装播种机并切到“配比”后，先在起点点击“预览”，可旋转，再“确认”；首次直接按F也只生成预览。换开垦机准备全部标记地块，再换播种机种植。预览不改地、不扣料，确认时重查库存与现场。

共有109条可自动执行的季节布局，另2条冬季分支仅供参考。缺坑、缺种、季节改变或已种作物缺失会暂停；驶出计划区只提示下一格。完成后保留原计划，整片收获后必须点击“重规划”并确认下一轮，不会自动换起点、方向或配比。

## 配置与存档

配置只有语言（跟随游戏/中文/English）、模型相对倍率（75%/标准/125%/150%）和洒水音乐。音乐在Mod设置选择开启、关闭或静音；静音保留植物安抚，取消车辆内单独开关。

保存油量、货仓、车体/配件耐久、水量与配比，读档保持停工。旧仓库挂件迁移到独立挂点；旧打包车无展开位置时保留原归属并重试；旧v2配比保留现场并提示重规划，不复用过期坑位索引。
